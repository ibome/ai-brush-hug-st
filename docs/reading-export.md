# 图文阅读与导出

打开聊天后，进入灵画师侧边栏「图文阅读」。首次进入会读取当前聊天，也可以填写起始、结束楼层，再点击「读取图文」。楼层从 1 开始，包含用户消息；系统消息不显示。

## 阅读

- 已识别的生图标签替换为对应图片；智能配图按唯一的原文定位句插入，无法唯一定位时放在该条消息末尾。
- 只读取当前聊天、当前回复分支和当前选中的图片版本。其他聊天、旧分支、未选中的历史版本不会混入。
- 浏览器存图与酒馆服务器存图都会检查；某一存储不可用时仍可阅读正文，并显示提示。
- 「阅读设置」可调整字号、行距、图片宽度，以及是否显示用户消息。每页显示 30 条正文，底部翻页。
- 阅读页先显示缩略图，点击图片查看原图。缺失、已删除或未生成的图片显示占位，不会自动补画。
- 正文采用安全的纯文本排版，保留换行；消息里的 HTML、脚本、远程图片和 Markdown 代码不执行。

## 导出

「导出 HTML」生成单个文件，将原图内嵌，断网也可直接用浏览器阅读。保留当前阅读设置和主题颜色，也可用浏览器打印功能另存为 PDF。

「Markdown ZIP」包含 `阅读.md`、`images/` 原图目录及 `图文清单.json`。解压后保持目录结构，用支持 Markdown 的编辑器查看。正文中的特殊语法会转义，图片使用相对路径。

导出包含所选正文、角色显示名及原图，不额外加入接口地址、秘钥、请求参数或内部聊天绑定。原图自身已有的生成元数据会保留；准备分享时请检查正文与图片是否包含个人信息。

导出前后会核对正文、回复分支与图片版本。修改范围后需重新读取；聊天被编辑、换分支或配图版本变化时，旧导出会中止。缺失原图会在 HTML 中占位，或记录在 ZIP 的图文清单里。

每次最多读取 3000 条消息、400 万字符、600 处配图；原图与正文合计最多 64 MB，单张原图最多 20 MB。超限时请缩小楼层范围。文字模型和生图接口不会因阅读或导出被调用。
