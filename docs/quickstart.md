# 新手入门

[返回教程目录](../README.md)

目标：配置一个接口，生成一张图片，保存一个可复用预设。

## 1. 安装并打开

1. 在酒馆「扩展 → 安装扩展」粘贴 `https://github.com/ibome/ai-brush-hug-st`。
2. 安装完成后刷新页面。
3. 在扩展设置里打开「灵画师」，或点击人物悬浮图标，再选「设置」。
4. 手机上导航栏可以横向滑动，查看后面的生图工坊、绘图管理、更新日志。

管理员希望所有账号使用时选择所有用户安装；只想自己使用时安装到当前账号。需要服务器组件的部署方法见 [安装与更新](install.md)。

## 2. 选择生图服务

打开「插件设置」，保持插件启用，选择自己已经拥有的服务：

| 已有资源 | 选择 |
| --- | --- |
| NovelAI 官方秘钥、蛋糕生图或砂糖绘画的已适配秘钥 | NovelAI |
| 提供 OpenAI 格式图片接口的服务与 Key | OpenAI 兼容 |
| 能访问的 ComfyUI 和 API 格式工作流 | ComfyUI |
| 已启用 API 的 SDWebUI | SDWebUI |

不要把文字聊天模型当成图片模型。选定模式后打开「接口配置」，跟随 [接口教程](interfaces.md) 填写地址、秘钥和模型。

默认的图片存储位置是浏览器。若界面提示任务组件未启用，请先让管理员安装服务器组件；仅切换图片存储位置不能替代任务组件。

## 3. 先完成一次手动生图

以 NovelAI 为例：

1. 填入自己的 Key，使用默认模型 `nai-diffusion-4-5-full`。
2. 点击「测试连接」，核对识别出的服务。
3. 到「生图工坊」，先不添加参考图和复杂角色配置。
4. 正向提示词填 `1girl, garden, soft light, anime illustration`，负面词填 `low quality, blurry`。
5. 选择较小的预设尺寸，每次生成一张，点击「生成图像」。
6. 等待主题小人旁的任务阶段变为完成，在「绘图管理」确认图片已保存。

测试连接与获取列表通常只验证连接或列举权限。只有实际生成成功才能确认这组接口、Key、模型和参数可以绘图；实际请求可能消耗服务额度。

## 4. 保存预设

1. 配置可用后，在参数预设区域点击「另存为」，输入容易辨认的名称。
2. 后续使用时，先选择预设，再点击「载入预设」。
3. 修改常用配置后点「保存预设」；想保留旧配置时再次「另存为」。
4. 有多个服务时，先建立 [命名接口](interfaces.md)，再把预设关联到对应接口。

自动保存当前输入与保存命名预设是两件事。预设保存了当时的参数，修改后需要保存才能更新它。

## 5. 在聊天中出图

让角色输出：

```text
image###1girl, garden, soft light, anime illustration###
```

「插件设置 → 触发与展示」默认开启自动生图和聊天内显示，默认不要求生成前确认。只有新完成的角色回复会自动处理；旧消息可手动点击「给这条配图」。

插件不会自动要求文字模型输出这个格式。需要在你使用的角色设定、提示词或酒馆预设中约定格式，也可以先手动测试包含标签的消息。详细说明见 [聊天教程](chat-assistant.md)。
