# 角色与提示词素材库

[返回教程目录](../README.md)

建议先让一个普通预设能稳定生成，再逐项加入角色、画风和标签，方便判断是哪项变化影响结果。

## 多角色档案

入口：「角色档案」。档案不修改酒馆角色卡，而是保存绘图所需的外貌、服装和参考信息。

### 手动建档

1. 点「新建角色」，填写名称。
2. 关联酒馆角色卡；绑定使用头像文件标识，同名卡不会因此混用。
3. 填头发、眼睛、体型、辨识特征、固定外貌和负面标签。
4. 添加服装方案，为每套填写名称和提示词，设置默认服装。
5. 需要时上传人物参考图，选择外貌／服装锁定。
6. 点击「保存档案」。

每个账号最多 100 个档案，每个档案最多 20 套服装，一次画面最多 6 个出场角色。参考图能否直接用于人物参考取决于图片模型。

### 出场人物与聊天覆盖

工坊和助手里的「出场人物」可自动关联当前酒馆角色，也可手动选择。为每人指定服装、动作、表情、画面位置和本次正负标签。

全局档案用于日常复用；切换到当前聊天后保存的是聊天覆盖，只影响这段聊天。点「恢复全局档案」可撤销该覆盖。手动清空出场人物后，该聊天不会继续自动加回，重新启用自动关联即可恢复。

锁定外貌／服装用于限制助手根据剧情改变固定设定；明确填写的动作与表情优先。原生多角色能力的 NovelAI 模型按角色分栏发送，其他模式按其支持方式组织文字，不能保证每个模型都精确理解位置。

### AI 创建档案

1. 先在提示词助手里配好文字模型。
2. 点「AI 创建档案」，选择最多 6 张酒馆角色卡，或粘贴设定。
3. 生成后检查外貌、服装与待核对信息，修改不准确的标签。
4. 已有档案时选择仅补全空白、对比更新或另建档案。
5. 对比更新时勾选确实需要改变的字段，最后保存选中的草稿。

复用助手的文字来源、模型和输出 Token，默认 4000。长卡或输出不完整时减少卡片数，再按需要提高输出长度。

只发送所选角色卡设定，不额外读取聊天和世界书。临时动作不应当作固定外貌，未知特征需要核对。模型不能决定角色绑定或档案 ID；保存前会核对来源和目标档案是否变化。关闭窗口不保存草稿，也不自动生图。

档案支持 JSON 导入导出，同 ID 导入会确认覆盖；跨设备携带参考素材请用配置备份。

## 画师串库

入口：「画师串库」。

1. 点「新建」，或「保存当前画风」读取当前参数。
2. 填名称、分类、适用模式，以及画师串／风格描述。
3. 按需要填写关联质量词、关联负面词、收藏和预览图。
4. 点「保存」。
5. 选替换或追加方式，决定是否带入关联词，再应用到当前生图参数。

工坊也有快捷选择。适用模式是组织与筛选信息，应用前仍要核对当前模型。ComfyUI 还要有对应提示词映射。画师串库支持搜索、分类、复制及 JSON 导入导出。

## 中文标签库

入口：「中文标签库」，或提示词框旁的选词按钮。内置 **1217 个标签、35 类**，可按中文、英文或别名搜索。

### 直接追加

1. 从要修改的提示词框旁进入标签库，先核对目标字段。
2. 搜索标签，点击添加到当前提示词。
3. 收藏常用标签，或从最近使用中重复选择。

追加使用英文标签，尽量识别重复词。负面词入口只在模型／节点支持时开放，不会把任意 OpenAI 模型当作支持独立负面词。

### 标签详情与自定义

眼睛按钮可查看释义、别名、分类提示和 Wiki。部分常用词有主题插画示例，点击查看时才加载；示例不是控制所有变量的生成效果对照。

可新建自己的词条，填写中文名、英文标签、别名、释义、HTTPS 来源与小图。示例图最长边压缩为 192 像素，最多 60 KB。最多 500 项自定义词和 100 组模板，共享 300 KB 标签库文件容量。

导入导出 JSON 可迁移自定义内容、收藏和模板；配置备份也能携带。内置词表随版本提供，不需要从外部标签站实时下载。

### 组合编辑与素材卡

1. 切到组合编辑，载入整段提示词作为草稿。
2. 在正向「想要」和负面「不想要」两栏选词，排序、拖动、移除或去重。
3. 勾选条目组成分组，可调整组和子项权重；解散时保留权重关系。
4. 核对两栏后点「应用正负组合」。

跨栏移动会携带权重，重复项会提示；撤销同时还原相关两栏。未知词和不支持的语法保留原文。草稿不会边编辑边覆盖原提示词。

内置 14 组模板，可追加或载入；自己的组合可保存为素材卡，记录分类、收藏、模型标记、分组名称和颜色。素材卡可用 `<分类:名称>` 引用其他卡片，应用时展开；缺失、重名、循环或超长引用会阻止应用，最多 8 层。

模型标记只是提示，不自动切换模型；分组名称和颜色也不进入发给模型的文字。

## 可视化提示词编辑

入口：提示词框旁「可视化编辑」。

1. 在正向、负面、画师／风格之间切换，选择原文或中文标签块视图。
2. 拖动排序、进出分组，或用移动按钮调整；手机也可用上下移动完成。
3. 多选后可复制、删除、跨栏移动或保存素材卡。
4. 调整精确权重，查看提交前预览。
5. 点击「应用」写回；取消则保留原参数。

预览按当前接口合并画师与主提示词，并显示角色档案内容；原生多角色参数分栏展示。服务端另加的质量词或私有处理不在预览里。

NovelAI、SDWebUI 和 ComfyUI 按各自可用语法处理权重；普通自然语言图片模型不默认套标签权重。ComfyUI 需核对工作流接受的语法，复杂调度／交替文本保持原文。

编辑单图、本图角色、角色档案、服装或画师串时，只改相应草稿。应用前若原字段被其他操作改动，会阻止覆盖，重新载入再编辑即可。草稿的撤销记录只在当前页面会话有效，要长期保留请应用或保存素材卡。
