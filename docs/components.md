# 扩展组件

入口：灵画师侧边栏「扩展组件」。

## 内置账号图片存储

无需另外安装。在「插件设置 → 图片存储」选择「酒馆服务器」即可。

| 内容 | 当前账号目录内的位置 |
| --- | --- |
| 原图 | `user/images/linghuashi/lh-图片ID.png`（或 JPG、WebP） |
| 缩略图 | `user/images/linghuashi-thumbnails/` |
| 参数、收藏、版本记录 | `user/files/linghuashi-image-图片ID.json` |
| 聊天关联 | `user/files/linghuashi-chat-关联ID.json` |
| 参考素材 | `user/files/linghuashi-reference-内容哈希.bin` 和同名 JSON |

这些路径由酒馆按当前登录账号解析。插件代码目录只放代码和主题资源，更新插件不会覆盖个人作品。每张图片单独保存参数，两个设备新增不同图片不会争抢同一份图库索引。参数文件移除接口秘钥与凭据引用。多个设备同时修改同一条参数记录时，以最后一次保存为准。

刷新和换设备后均可读取已保存的图片与参数。任务记录、待保存接口响应保留在当前浏览器，清除站点数据前请完成任务并导出备份。内置清理仅在页面运行时执行，保留收藏与聊天配图所在的整个版本图组。

大型图库首次读取需要逐张读取参数文件。高频多设备协作或较大图库建议使用增强组件。完整素材清单由增强组件提供，内置素材通过配置、作品和备份中的引用读取。

## 服务器增强组件

可选组件：`linghuashi-storage`。

TauriTavern 不支持 Node 服务端组件，会直接使用内置图片和文件接口，并在组件页标记「当前客户端不支持」。「酒馆服务器」在该客户端中保存到本机 TauriTavern 数据目录，任务在当前设备恢复。见 [TauriTavern](tauritavern.md)。

- 任务和已接收结果保存在酒馆服务器，同账号换设备可继续恢复。
- 服务器执行锁协调同账号多个页面或设备。
- 关闭页面后继续按规则清理组件保存的作品。
- 保留旧版服务器图库、聊天关联、参数和参考素材的兼容。

### 下载与安装

1. 点击组件条目的「下载组件」，解压 ZIP。
2. 由管理员把 `linghuashi-storage/` 文件夹放入 `SillyTavern/plugins/`。
3. 在 `config.yaml` 中启用 `enableServerPlugins: true`。
4. 按原来的启动方式重启酒馆。
5. 回到「扩展组件」点击「检测组件」，确认显示「已安装」且协议兼容。

组件下载包名称跟随前端发行版本，内部组件自身版本可能不同，以协议兼容状态为准。此版本使用存储协议 2。

SillyTavern 的前端扩展安装接口不能安装服务器组件，因此服务器增强部分需要管理员操作。普通用户可把下载包交给管理员。需要限制使用账号时，管理员可保留或配置 `allowed-accounts.json`；未授权账号仍可用酒馆内置存图，但无法读取增强组件的旧记录。

后来安装组件后，原先的内置图库和当前浏览器任务仍可读取，新任务使用增强组件。原先的内置图片仍在页面打开时清理，组件后台只清理自己管理的作品。组件不会让尚未返回结果的同步生图请求在关闭网页后保证完成。

## 浏览器图片存储

同样内置，无需下载任何组件。作品保存在当前浏览器 IndexedDB，不自动同步其他设备。可以从图片存储设置复制到酒馆账号，原浏览器作品保留。
