# 教程配图说明

[待发布教程目录](../../preview/README.md)

这些图片用于 2026-10-23 待发布功能教程。不是当前 GitHub 安装版的界面承诺，也不是新功能的下载入口。

| 文件 | 来源与用途 |
| --- | --- |
| `first-use.webp` | 隔离测试环境，展示首次使用目标和验证状态 |
| `assistant-entry.webp` | 隔离测试截图裁切，展示任务提示词编辑入口 |
| `task-rules.webp` | 隔离测试截图裁切，展示规则正文、动态标记与保存按钮 |
| `draft-recovery.webp` | 隔离测试截图裁切，展示恢复中心的几类草稿 |
| `comic-result.webp` | 酒馆测试版的中性演示项目“晨风来信”，展示两格排版 |
| `comic-dialogue-mobile.webp` | 隔离 WebKit 测试，展示手机气泡直接编辑 |
| `comic-protection-mobile.webp` | 隔离 WebKit 测试，展示手动主体保护区 |
| `comic-format-repair.webp` | 隔离测试，展示故意构造的 JSON 引号错误与修复预览 |
| `reading.webp` | 隔离测试截图裁切，固定样图占位，展示图文阅读入口 |
| `debug-tools.webp` | 隔离测试，展示网络、存储和失败记录入口 |
| `characters-mobile.webp` | 酒馆测试版的角色档案列表，仅展示手机排版 |
| `local-component-check.webp` | 隔离测试，故意填写无效地址展示组件验证错误 |

图片经过尺寸控制、WebP 压缩及必要裁切；未伪造按钮或替换界面结果。隔离环境中的样图、测试角色名称和故意构造的错误只用于演示，不应作为默认配置照填。本次文档制作没有提交新的付费文字或生图请求。
