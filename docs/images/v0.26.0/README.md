# 0.26.0 教程配图

本目录六张 WebP 为专门制作的中文流程示意图，不是酒馆截图，也不是图片模型的生成结果。示意图用来解释功能路线、数据关系、计费边界与恢复顺序，按钮位置以实际界面为准。

| 文件 | 内容 |
| --- | --- |
| `overview.webp` | 手动绘图、聊天配图、漫画和导出路线 |
| `first-run.webp` | 接口、模型、第一张图与参数保存 |
| `assistant.webp` | 酒馆预设、任务规则、上下文、文字与图片模型 |
| `comic.webp` | 剧情、分镜、画格、气泡及导出 |
| `recovery.webp` | 草稿、任务、原图与备份的区别 |
| `mobile.webp` | 设备直连、酒馆转发、可选组件及调试 |

配图不含账号数据、聊天原文、接口凭据或私有日志。鲸鱼图案沿用项目现有主题资源。旧 `2026-10` 图片保留用于历史文档兼容，新教程不再依赖截图。
