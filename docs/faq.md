# 常见问题

[返回教程目录](../README.md)

## 测试连接成功，为什么仍然无法生图？

连接测试、模型列表和图片生成是不同权限。先用一个明确支持的图片模型、小尺寸、一张图实际测试，再看服务返回的具体错误。检查额度、图片权限、模型名、尺寸和第三方参数。

「生图权限尚未验证」表示尚未通过实际图片请求验证，不要求额外点击一个隐藏的授权按钮。

## 获取模型列表没有目标模型怎么办？

展开完整列表并清除搜索条件，核对已获取数量。模型名可直接手填。服务如果没有返回某个模型，插件不能通过前端补出其权限；请检查服务账号与模型列表接口。

列表包含文字模型也不代表它们能图片生成。助手文字模型与工坊图片模型分别选择。

## OpenAI 兼容接口应该填到哪一级？

通常填服务根地址，例如 `https://example.com` 或 `https://example.com/v1/`，末尾斜杠可有可无。代理子路径要保留，生图路径在连接选项单独设置。查看请求预览，确认没有重复路径。

## OpenAI 格式里的 NAI 负面提示词填在哪？

模型名包含 `nai-diffusion` 时，独立负面提示词框自动出现。直接选择服务实际返回的完整模型名。普通图片模型不一定有原生负面参数。

## 刷新后 Key 看不到了？

先区分空值和密码遮罩：点击眼睛按钮查看，核对当前模式、命名接口、参数预设及账号。检查秘钥输入后的保存状态；修改命名接口后点击「保存当前接口」，修改预设后点击「保存预设」。

换设备、换浏览器或导入分享包后，凭据不一定存在。分享包不会带 Key，跨设备迁移需要含秘钥的加密备份。不要在问题截图里露出完整秘钥。

## 提示「秘钥未保存」，另存为预设和生图都失败？

这是秘钥存储环节失败，不能据此判断服务商 Key 无效。修复后的保存流程会在酒馆秘钥接口不可用时改为本机保存，浏览器设置缓存不可写时再尝试独立数据库；成功后会标明保存位置。

更新后重新填写一次秘钥，等待显示「秘钥已保存…」，再保存接口或预设。若仍失败，按错误提示检查站点权限、隐私模式或存储空间，到「调试工具」检测存储与缓存并反馈日志。不要反复生图或直接清空站点数据。详见 [秘钥保存与排错](interfaces.md#秘钥保存位置与失败处理)。

## 打开插件时报 exceeded the quota 或载入超时？

如果报错包含 `setItem`、`tavern-draw-preview-ui-v1` 和 `exceeded the quota`，表示浏览器为当前酒馆地址提供的设置缓存空间不足。同一地址下的酒馆及其他扩展也可能使用该空间。

更新到 0.23.1 或更高版本并刷新酒馆。设置缓存不可用时，界面仍可打开，配置继续通过酒馆账号设置同步；图库初始化也不再依赖清理时间能否写入缓存。页面中的缓存状态是非弹窗提示。

此修复不会扩大浏览器配额。保存在浏览器中的秘钥或图片如果也无法写入，仍需备份并整理相应存储；新增秘钥保存失败会明确提示。不要直接清空整个站点数据，以免丢失本地凭据、浏览器作品和其他扩展数据。

## ComfyUI 参数灰色、修改不生效？

展开节点映射，检查该参数是否对应 API 工作流里的正确节点。未映射会保留原工作流值；复杂多分支需要指定正确输入和输出。先在 ComfyUI 自己运行成功，再导入 API 格式 JSON。

## 图片始终没有出现在聊天里？

检查插件是否开启、图片接口是否可用、「在聊天中显示图片」是否开启、输出前后缀是否和设置一致。等待角色回复结束，不要用用户消息测试自动触发。

历史消息不自动补画，用「给这条配图」手动处理。生成成功但图片缺失时，核对存储位置以及原会话、消息和回复分支是否对应。

## 图生图和局部重绘为什么看起来相似？

两者都用底图，局部重绘还要编辑蒙版；图生图整体变化，局部重绘限制目标区域。只上传一张底图并不代表已经画好蒙版。参考 [高级生图](generation.md)。

## 智能配图为什么没有自动运行？

「自动生图」用于已有提示词标签；无标签剧情需要提示词助手的「自动准备配图提示词」。准备后是否自动出图还由另一个开关控制，默认都关闭。

核对文字接口、模型、输出 Token、配图频率与上下文。助手报错不会无限自动重试，可以先手动准备一条草稿。

## 为什么刷新后要手动继续任务？

未提交任务需要确认后继续，避免刷新触发重复生图。已返回图片可以继续保存；已提交但结果不明时先到服务端核对。详见 [任务恢复](gallery-tasks.md)。

## 浏览器模式和酒馆服务器模式图片数量不同？

两者是不同图库，切换不会自动搬迁。服务器存储页的迁移按钮可处理浏览器作品；先备份，再核对结果。清除浏览器站点数据可能删除浏览器作品和本地凭据。

## 远程接口报跨域、Mixed Content 或无法访问？

请求通常从浏览器发出，接口需允许酒馆站点访问。HTTPS 页面连接 HTTP 服务可能被浏览器拦截，应由管理员配置 HTTPS 入口和跨域。`127.0.0.1` 指当前浏览器所在电脑。

0.24.0 起，设备网络检测集中到侧边栏「调试工具」，连接失败时点击「打开调试工具」即可进入。选择对应接口并开始检测后，可复制脱敏日志给作者。请在实际出问题的设备上检测；不用另外提供秘钥或私人聊天。具体步骤见 [设备网络检测](interfaces.md#连接失败时检测设备网络)。

手机已开代理、能打开其他外网，也不能证明当前 NAI API 路径正常。0.23.3 起，官方连接测试改用图片服务的订阅接口；旧版日志中 `api.novelai.net` 失败而 `image.novelai.net` 返回 200 时，先更新后重测。检测区分普通请求、带认证请求和不透明辅助响应，但不能直接读取代理开关，也不能凭统一的浏览器错误确定 DNS、TLS 或跨域原因。手机本地部署酒馆时，地址栏的 `127.0.0.1:8000` 本身不需要修改。

## 前端 0.21.1，服务器组件却显示 0.21.0？

0.21.1 只增加更新日志与文档，配套组件自身版本仍为 0.21.0，存储协议为 2，这是当前发行的正常组合。只有协议／能力不匹配或组件确实过旧时才需要处理。

## 手机找不到绘图管理或更新日志？

窄屏导航在上方横向滚动，向左滑动导航条即可看到后面的入口；也可以从扩展设置的更新提示打开更新日志。

## 手机提示词助手无法选择模型，页面反复闪动或跳动？

先更新到 0.24.1 并刷新酒馆。本版避免后台任务同步反复重建助手表单，文字模型改为可搜索、直接点选的列表。

填好独立 API 地址与 Key，点「获取文字模型列表」，在展开的列表中点选；也可手动填模型名。401／403 通常需要核对助手 Key 或接口权限；网络、超时及格式错误会在模型旁提示。模型列表查询不提交生图或文字生成，失败不会无限重试。

## 生图时不流畅，或提示生成、保存失败？

0.24.0 起会按失败阶段区分浏览器配额、图片解码、服务器上传限制、权限与网络问题。更新后先复现一次，再到「调试工具」检测存储与缓存，复制日志反馈。

已有图片响应时，优先尝试「继续取图 / 保存」。先备份再整理作品，不要直接清空整个站点缓存。可用顺序队列、并发 1、每次 1 张和较小尺寸比较是否改善。浏览器容量估计不能判断酒馆服务器磁盘。步骤见 [调试工具](debug-tools.md)。

## 普通 HTTP 酒馆报 crypto.randomUUID is not a function？

更新到 0.24.0 后刷新，插件已兼容缺少原生 UUID 与 SHA-256 的环境。加密备份仍需 HTTPS 或本机安全环境，普通备份、生图与图片校验可以继续使用。

## 更新后想回退怎么办？

从旧版 Releases 取对应代码，并恢复升级前同版本的配置备份。先保存当前需要的作品；不要假设旧代码能直接读取所有新配置。见 [安装与更新](install.md)。
