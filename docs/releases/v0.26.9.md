# 灵画师 0.26.9

本版优化聊天图片切换画风后的重新生成。前端构建标识为 `20261106-preset-reroll`，可选服务器组件保持 **0.21.2 / 协议 2**。

## 使用方法

1. 在「生图工坊」或「接口配置」载入希望使用的参数预设，也可直接修改当前正向提示词、画师串与负面词。
2. 回到聊天，点击图片下的「再画一张」。
3. 新版本使用当前画风，原图的场景、角色动作、模型和尺寸继续保留，可通过版本选择切回旧图。
4. 想按原图画风继续抽图时，打开图片的更多菜单，选择「沿用原图画风再画一张」。

新聊天配图分别保存预设前缀与场景，连续换风格不会叠加旧预设。旧图片与聊天标签精确对应时也能分离旧前缀；无法确定分界的旧图保留原内容，避免误删场景，可用本图提示词编辑调整。

参数预设需点击「载入预设」才生效。酒馆文字预设、助手模板和底层规则影响下一次分析，点击「再画一张」不会重新调用文字模型分析剧情。

## 更新方法

更新插件后刷新酒馆一次，在「更新日志」核对版本 **0.26.9**。无需重填 API、清空图片或重启酒馆。
