# 灵画师 0.23.1

修复部分自建酒馆打开灵画师时，因浏览器设置缓存空间不足而显示 `exceeded the quota`、随后无法载入的问题。

- 本地设置缓存写入失败不再阻断界面启动或当前酒馆账号的配置同步；缓存恢复可用后继续写入。
- 图库初始化及清理时间记录允许设置缓存不可用，保留既有图片、配置与其他扩展数据。
- 以页面内状态提示替代中断启动，真实启动错误也不会再被后续“载入超时”覆盖。
- 浏览器秘钥保存失败提供明确提示，既有秘钥引用继续保留；此修复不会扩大浏览器存储配额。

已遇到该问题的用户可从酒馆扩展管理更新灵画师，再刷新酒馆，无需清空站点数据。

服务器组件保持 0.21.0／协议 2，已安装兼容组件时无需重启酒馆或重装组件。
