# v0.25.0

新增 TauriTavern v2.3.0 兼容，修复其缺少普通酒馆账号查询接口时灵画师无法启动的问题。

- 使用本机默认账号和宿主内置图片、文件接口保存作品、参数、参考素材与聊天关联。
- 任务在当前设备保留并恢复，不再探测不支持的 Node 服务端增强组件。
- 兼容特殊协议下的界面通信与更新路径，旧 WebView 没有 Popover 接口也能打开控制台。
- 跟随酒馆查询模型时保留自定义接口格式、OpenCode 渠道与凭据选择，助手选模不修改聊天模型。
- 调试日志标记 WebView 直连与本机存图，补充代理和客户端分发限制说明。

安装方式与限制见 [TauriTavern 教程](https://github.com/ibome/ai-brush-hug-st/blob/v0.25.0/docs/tauritavern.md)。插件独立 API 不会自动使用宿主 Request Proxy。公开 iOS TestFlight 默认关闭第三方扩展；需要使用宿主允许安装和运行扩展的版本。

已完成自动化兼容接口与浏览器回归，尚未完成 TauriTavern 真机验证。普通 SillyTavern 安装方式不变；现有配置、秘钥和图库无需重置。可选服务器组件继续使用 0.21.0。
