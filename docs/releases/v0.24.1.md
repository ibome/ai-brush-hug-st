# 灵画师 v0.24.1

本版修复手机端提示词助手输入及模型选择被页面刷新打断的问题。

- 后台任务同步保留助手表单、输入焦点和滚动位置，避免定时整页重建。
- 模型列表可展开、搜索和直接点选，同时保留手动填写；限制同时显示数量，可搜索全部模型。
- 查询期间修改地址、Key 或模型来源会取消旧请求，过期结果不会覆盖当前列表。
- 模型错误在配置区域显示，区分鉴权、权限、限流、超时、网络及返回格式问题，不清空已选模型或自动重试。

通过酒馆扩展更新或「更新日志 → 立即更新」升级，然后刷新酒馆。服务器组件仍为 0.21.0／协议 2，无需重装。

操作步骤见 [聊天联动与提示词助手](../chat-assistant.md)。
