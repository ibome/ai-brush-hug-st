# 灵画师 0.26.8

本版修复后台查询打断手机输入、阅读位置和已展开内容的问题。前端构建标识为 `20261105-passive-refresh`，服务器组件保持 **0.21.2 / 协议 2**。

## 修复内容

- 后台任务查询只更新进度、任务、图片结果和保存状态，不再定时重建当前设置页面。
- 相同任务、相同生成结果不重复重绘；正在填写的输入框、光标选区、草稿和滚动位置保持。
- 画师串搜索只更新匹配列表，避免输入时重建搜索框；当前配置说明展开后保持展开。
- 图库数据未变化时保留当前列表和查看器；聊天卡片未变化时保留原图、提示词详情和图片菜单。
- 聊天状态变化时更新对应卡片，保留展开选择；图片生成完成后仍自动插入，组合任务也继续显示最新进度。

## 更新方法

在酒馆扩展管理更新灵画师，刷新页面一次加载新版。更新后可在「更新日志」核对版本 **0.26.8**。无需重启酒馆，也无需清空设置、秘钥、图片或任务。

## 验证范围

覆盖隔离浏览器中的后台多轮查询、模拟输入法组合输入、光标选区、设置页与阅读滚动、聊天卡片和新任务状态变化。使用局域网 HTTP 与手机宽度测试；真实手机键盘仍需结合用户设备验证。测试使用模拟任务和安全示例图片，不会提交实际付费生图请求。
