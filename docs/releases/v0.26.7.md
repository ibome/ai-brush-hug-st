# 灵画师 0.26.7

2026-11-05 发布。继续修复部分手机用户「图片已在绘图管理生成，聊天仍显示生成图片，需要整页刷新」的问题。

## 修复内容

聊天区域持续有其他界面变化时，旧的配图刷新计时器可能反复重新计时，导致生成进度和图片迟迟无法更新。本版保留第一次更新的执行时间，不再被后续变化无限推迟。

聊天卡片一次只执行一轮异步重绘。存储读取较慢时，先完成当前更新，再合并显示随后收到的状态，避免多轮重绘互相干扰。

已观察到的流式输出明确结束或停止后，即使酒馆遗漏结束通知，也能恢复配图刷新。正文正在输出期间继续避免改写消息。

这些恢复操作只更新显示和查询已有结果，不会自动重新提交生图。

## 切换角色卡更快识别标签

切换角色卡或会话后，先读取当前配图的关联记录，识别提示词标签并显示配图入口，完整任务与图库扫描在后台继续。已显示图片在后台检查时保留，不会先换成空白。

酒馆账号存储减少重复读取，只为当前会话读取相关的聊天关联文件。点击生成后，等待任务核对期间也显示准备状态；真正提交前仍检查已有任务，不会为了提速跳过重复提交保护。

## 更新方法

1. 等待当前生成结束，在酒馆扩展列表或「更新日志 → 版本与更新」更新插件。
2. 更新后刷新酒馆一次，加载 0.26.7；之后完成的聊天配图应自动显示，无需反复刷新。
3. ZIP 安装用户使用 `ai-brush-hug-st-v0.26.7.zip` 覆盖插件代码后刷新。

配置、秘钥、图片和任务记录保留。本次仅更新前端，可选服务器组件仍为 **0.21.2／协议 2**，无需因此重启酒馆。

已通过 703 项自动化测试，以及局域网 HTTP、手机尺寸视口、持续聊天变化、慢速服务器存储、首次标签识别和流式结束通知缺失的隔离浏览器回归。隔离测试使用模拟任务和普通湖畔图片，不消耗生图额度；尚未在反馈用户的手机硬件上验证。
