# 灵画师 0.23.2

连接失败时可在出问题的手机或电脑上检测当前浏览器网络，并复制日志反馈。

- 「接口配置」测试连接失败后显示「检测当前设备网络」，覆盖 NovelAI、OpenAI 兼容、ComfyUI 和 SDWebUI；官方 NAI 分别检查账号与图片域名。
- 检查只使用 GET 请求，不提交生图、文字生成或工作流。展示 HTTP 状态、耗时、超时、协议冲突及可捕获的安全策略拦截。
- 不透明响应仅供辅助判断；不会把它当作跨域、鉴权或生图权限通过，也不会凭浏览器的统一错误武断判断代理、DNS 或 TLS。
- 检测面板随当前主题显示，支持停止、重新检测、复制与下载日志；自动复制受限时可选中文本手动复制。
- 日志隐藏秘钥、认证头、账号密码、自定义地址路径及查询参数，不包含响应正文、模型列表、聊天或提示词，不自动发送或保存到账号。

使用步骤见：[接口配置与设备网络检测](https://github.com/ibome/ai-brush-hug-st/blob/main/docs/interfaces.md#连接失败时检测设备网络)。

服务器组件仍为 0.21.0／协议 2，本次前端更新不需要重装组件或重启酒馆。
