# 灵画师 0.26.14

2026-11-17。本次完善从构思、角色换装、检查参数到实际出图的创作流程，并修复 dzmm 实测中的助手、图片编辑与手机导航问题。

## 创作方式与生图预览

生图工坊、提示词助手和漫画工坊增加统一的创作方式切换。已有提示词可继续编辑，也可交给 AI 构思；切换时保留已有助手草稿。

1. 在生图工坊填写提示词，选择接口、模型和尺寸。
2. 打开本地生图预览，核对画师风格、场景正向词、基础负面词与角色外貌服装。
3. 检查模型、尺寸、角色分栏和提示词来源。局部重绘同时显示实际提交的模型；适用时显示透明背景状态。
4. 修改参数或应用新的服装后重新预览，再决定是否生成。

预览只在本地整理参数，不提交文字或图片生成请求。更多步骤见[生图工坊](https://github.com/ibome/ai-brush-hug-st/blob/main/docs/generation.md)。

## 角色换装与草稿

出场人物可选择跟随档案、服装库、自定义或 AI 决定。换装范围可以是仅下一次、当前聊天、全局默认或漫画项目。

1. 选择出场人物，为每位角色设置服装方式与内容。
2. 根据用途选择范围：临时尝试选仅下一次；持续剧情选当前聊天；漫画连续画面选漫画项目。
3. 先应用草稿，再检查本地生图预览。尚未应用就点击手动生成时，会提示应用后生成、沿用已应用配置或取消。
4. 改错时使用单角色撤销。多角色草稿会先全部校验，通过后再应用。

未应用草稿在本次页面中按聊天分别保留，切换聊天后可以返回继续编辑；整页刷新不保证保留这些临时草稿。漫画项目换装不修改全局档案和历史图片。更多说明见[角色与素材库](https://github.com/ibome/ai-brush-hug-st/blob/main/docs/libraries.md)。

## 提示词助手

- 跟随酒馆时不再显示未使用的独立 API 秘钥错误。
- 模型列表只列出实际取得的模型；当前手填模型缺失时显示核对提示，仍可手动尝试。页面显示当前实际调用模型。
- 新增“仅处理本次输入”。单独生成、翻译或润色时，开启后跳过聊天、角色卡和世界书提取；聊天自动配图继续使用聊天上下文。
- 查看失败诊断会展开对应调用记录，切换角色档案、漫画项目或发起其他任务后也不会误用最新的其他诊断。

在 dzmm 中使用可用文字模型实际完成了一次独立场景分析，验证了跟随酒馆调用、结构化解析与草稿保存。不同用户的模型权限仍取决于其服务。排错见[助手调用诊断](https://github.com/ibome/ai-brush-hug-st/blob/main/docs/chat-assistant.md#助手调用诊断)。

## NovelAI V5 与图片编辑

完善 V5 Full／Curated 的图生图、局部重绘和透明 PNG 参数，同时保留 V3／V4／V4.5 兼容。V5 不启用 Vibe、人物参考、噪声调度和 Variety+；V5 Curated 局部重绘提示使用对应的 V4.5 Curated 重绘模型。

单图编辑和图库参考入口按当前接口能力开放。接口不支持图生图或局部重绘时，按钮显示不可用原因；缺少底图、蒙版或必要能力时禁止提交。参数适配不代表已替用户验证模型权限或额度，第三方接口也可能仅实现部分能力。

更多说明见[高级生图](https://github.com/ibome/ai-brush-hug-st/blob/main/docs/generation.md)和[NovelAI 图片增强](https://github.com/ibome/ai-brush-hug-st/blob/main/docs/novelai-processing.md)。

## 首张图片验证与手机体验

新人引导明确区分世界书标签生图与助手分析剧情。世界书标签流程只要求图片接口，不需要额外配置文字模型。

本次实际出图验证分别记录识别提示词、图片返回、成功保存与聊天加载，按当前接口、模型、存储和聊天显示结果。只有实际保存成功才更新存储验证，切换聊天或文字模型不会丢失同一账号与存储位置的成功存图证据。不会自动发送测试生图。

手机切换功能页后，当前导航项保持完整可见。漫画图片齐全进入阅读时，收起重复的下一步栏；不使用步数的接口不再显示无关的默认步数。

## 更新方法

先等待当前任务结束并导出个人备份，再到“更新日志 → 版本与更新”点击更新，完成后刷新酒馆一次。已有设置、秘钥、角色档案与图片继续保留。

可选服务器组件保持 **0.21.2／协议 2**。已使用该版本组件的用户无需重复安装或重启酒馆。普通酒馆账号存图也无需安装额外组件。
