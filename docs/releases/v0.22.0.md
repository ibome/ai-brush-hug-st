# 灵画师 0.22.0

普通「酒馆服务器」存图不再要求单独安装服务器组件，作品直接保存到当前酒馆账号目录。新增侧边栏「扩展组件」，集中查看内置功能、增强组件状态、下载与安装步骤。

- 内置账号存储包含原图、缩略图、参数、收藏、历史版本、聊天关联和参考素材。
- 每张作品独立保存参数，新增作品不会相互覆盖图库索引，参数不含接口凭据。
- 没有增强组件时，任务与待保存响应在当前浏览器恢复，已有增强组件继续提供跨设备任务恢复、执行锁和后台清理。
- 后来安装组件也保留先前的内置图库和当前浏览器任务。
- 原图在账号 `user/images/linghuashi/`，缩略图在 `user/images/linghuashi-thumbnails/`，参数与素材在 `user/files/linghuashi-*`。
- 九套主题适配组件区，手机也可查看状态、下载并展开安装步骤。

服务器组件仍为 0.21.0／协议 2。已安装兼容组件无需重装或重启，普通存图无需启用服务器插件。下载的服务器 ZIP 仍需管理员放入 `plugins/` 并重启，前端扩展安装入口不能代替此操作。

内置账号存储的自动清理在页面打开时运行，增强组件的后台清理仅处理其管理的图片。旧版组件、旧图库和个人配置保持兼容。详见 [扩展组件教程](../components.md)。
