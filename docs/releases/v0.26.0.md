发布日期：2026-10-24。构建：`20261024-comic-assistant-release`。

## 新人使用与配置

- 第一次打开可选择手动生图、聊天配图、制作漫画三条引导，之后从问号入口重新打开。
- 常用/完整设置减少首次操作负担；当前配置摘要区分已配置、连接通过和实际生图成功。
- 手机导航保留横向位置，功能页记住各自滚动位置；窄屏标题独占一行，操作按钮换行，主要操作就近显示。
- 命名接口、参数预设、助手方案分别管理服务连接、绘图配方和文字分析方式。载入方案前可核对自动化设置。

第一次使用建议先手动成功一张图，再配置文字助手，最后尝试两格漫画。[从安装到第一张图](https://github.com/ibome/ai-brush-hug-st/blob/main/docs/preview/first-run.md)。

## 漫画工坊

侧边栏新增「漫画工坊」，依次完成 **剧情与分镜 → 画格生成 → 排版与对白 → 阅读与导出**。

- 剧情可手写或读取聊天；项目保存独立人物、服装与参考图快照，不改全局角色档。
- 每章最多 12 格、6 个角色。分镜模型、预设、返回方式与输出上限可按项目设置，默认使用内置分镜规则。
- AI 分镜先预览再采用；失败原文可本地修复，引号修复会列出修改预览。单格 AI 修改先展示差异。
- 每格分别确认生图，可仅重试失败格，也可从图库选图、切换图片版本，已有原图保留。结果待核对时先查任务。
- 四种模板：竖屏条漫、经典四格、横向双列、竖幅双列；支持阅读方向、间距、比例、完整显示或裁切。
- 每格最多四个气泡，支持拖动、宽度、独立字号、对齐、层级及尾巴。手机默认紧凑编辑，详细设置按需展开。
- 主体保护区可手动框选、移动缩放，再预览气泡位置建议；它不是自动识别人脸。
- 修改对白与排版不会重新生图；支持撤销重做、编辑历史、待采用分镜和失败回复恢复。
- 系列最多 200 章、40 个分组，同时加载最多 8 章；支持续章、拆章、复制、归档、按需读取正文。
- 导出长图 PNG、分页 PNG ZIP、离线 HTML、项目 JSON、单章或系列带图包。导出前检查缺图、对白溢出、气泡重叠及保护区遮挡。

**当前尚无自由斜切分格、跨格叠放小格、竖排气泡和独立拟声字图层。** 图片画风、人物一致性与可用参考能力由模型和服务决定。详见 [漫画图文教程](https://github.com/ibome/ai-brush-hug-st/blob/main/docs/preview/comic.md)。

## 阅读、恢复与存储

- 「图文阅读」按当前聊天、回复分支和选中的图片版本排版；可调整阅读样式，导出离线 HTML 或 Markdown 与原图 ZIP。
- 「插件设置 → 草稿与恢复」集中查看规则、助手和漫画工作稿；导入先预览，恢复保留当前稿，不自动执行旧任务。
- 任务失败区分配置、网络、模型格式、图片处理、保存与结果待核对；已有结果优先继续取图或保存，避免重复生成。
- 酒馆图库增加本设备参数索引与分批核对；临时读不到存储不会直接判定原图已删除。
- 单章/系列 JSON 不含原图；带图包包含当前配图。旧图片版本与参考素材需按完整备份范围另行迁移。

详见 [草稿、图片与备份](https://github.com/ibome/ai-brush-hug-st/blob/main/docs/preview/recovery-export.md)。

## 可选本地组件

新增随发行提供的 `linghuashi-local-tools-v0.26.0.zip`，支持 WD 标签反推、FSRCNN 2×/4× 超分、四步安装向导和脱敏环境诊断。

组件在所安装的电脑执行，手机只连接使用。依赖与模型按需准备，前端不会自动安装；普通酒馆存图无需这个组件。现有服务器增强组件继续使用协议 2，兼容旧组件时无需重装。[手机、网络和组件教程](https://github.com/ibome/ai-brush-hug-st/blob/main/docs/preview/mobile-components.md)。

## 本次修复

- 聊天图片快速切换历史版本时显示等待状态，暂时禁用本图操作，防止点开上一版。
- 控制台冷加载超过等待时间但后来就绪后，后续命令可以使用已加载页面，不沿用旧超时结果。
- 只读看图不会阻塞智能配图；各操作按实际任务状态处理。
- 修复部分 iOS 浏览器提示词解析白屏和布局问题，避免窄屏标题被挤成竖排。
- 漫画拖动气泡或主体保护区不再导致页面跳顶，撤销保留图片版本与任务关联。
- 离开或刷新页面时不再继续发起新存储请求；取消离开或返回页面后可恢复。

## 升级与下载

1. 等当前任务完成，导出需要的配置、原图和参考素材备份；本设备未保存草稿另行导出。
2. Git 安装在酒馆扩展列表更新，或「更新日志 → 版本与更新」点击更新，完成后手动刷新。
3. ZIP 安装解压 `ai-brush-hug-st-v0.26.0.zip` 到原插件目录，保留自己的账号数据。
4. 核对显示 0.26.0；如有重复安装，先确认实际加载路径。
5. 服务器组件或本地组件按需下载，分别遵循对应安装说明，不能从前端安装扩展入口安装服务端组件。

| 文件 | 用途 |
| --- | --- |
| `ai-brush-hug-st-v0.26.0.zip` | 可直接安装的前端插件、教程与资源 |
| `linghuashi-storage-v0.26.0.zip` | 可选服务器任务/存储增强组件 |
| `linghuashi-local-tools-v0.26.0.zip` | 可选本地反推与超分服务 |
| `SHA256SUMS.txt` | 上述下载包的 SHA256 校验值 |

## 验证与已知限制

发布前 648 项自动化用例通过；此前已在 Chromium、WebKit 完成漫画、恢复、手机排版与连续刷新回归，在真实酒馆内置浏览器核对模型列表、导航、版本切换和存储诊断。未重新提交付费模型请求，也未完成每种真机浏览器和代理环境验证。

WebKit 自动化不等同于 iPhone Firefox/Safari 真机验证；小数据存储试写不代表大图一定保存成功。下载入口已提供，但文件是否落盘仍需到设备下载目录核对。独立 API 转发取决于酒馆上游网络与宿主能力。
