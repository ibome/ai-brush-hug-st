# 灵画师 0.26.13

本次更新优化提示词助手、AI 创建角色档案和漫画等共用的酒馆文字调用与错误诊断。

## 跟随酒馆

“文字模型”留空会跟随酒馆当前模型。手动选择了同一个模型、返回方式为“普通 JSON 回复”时，也优先使用酒馆原生调用。独立选择其他模型、使用接口 JSON 或工具模式时，继续使用酒馆聊天补全后端；不会修改正文模型设置。

## 调用失败怎么排查

1. 根据提示核对认证、模型权限、余额或配额、请求参数等对应配置。任务忙碌时，等待当前文字回复结束。
2. 如果提示响应格式异常，检查服务地址及返回方式。接口不支持 JSON／工具模式时改回“普通 JSON 回复”。
3. 在“提示词助手 → 助手调用诊断”查看实际模型、调用路径、失败分类和 HTTP 状态，再点击“复制脱敏诊断”交给作者。
4. 如果宿主未提供具体原因，请同时查看酒馆后端日志。HTTP 200 不代表上游模型一定生成成功；插件不会把未知错误直接认定为网络故障。

诊断会记录固定错误码、服务提供的酒馆与上游 HTTP 状态、已知参数及响应类型，不包含秘钥、聊天正文、模型回复、预设名称或接口路径。失败后不会自动重试文字生成，避免重复请求。

## AI 创建角色档案

角色草稿解析失败会正确记录为失败，并保留本页的失败回复供检查。JSON 错误不再一律建议提高 Token；先核对格式和额外说明，只有确认截断时再调整输出上限或减少角色数量。

## 更新方法

在酒馆扩展管理中更新灵画师，完成后刷新页面一次。服务器组件保持 0.21.2／协议 2，无需重启酒馆。

更多步骤见[提示词助手教程](../chat-assistant.md#助手调用诊断)。
