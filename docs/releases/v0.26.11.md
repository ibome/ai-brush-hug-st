# 灵画师 0.26.11

本版整理聊天图片下方的操作区，并补充逐张画风参考的编码状态。前端构建标识为 `20261112-chat-controls`，可选服务器组件保持 **0.21.2 / 协议 2**。

## 聊天图片操作

图片下方默认只显示「图片操作」，点击后展开重画、修改提示词、收藏、下载、历史版本、绘图管理和提示词查看，再点一次收起。

- 收藏、切换历史版本、读取图片记录和切换主题时保留展开或折叠选择；整页刷新后恢复默认折叠。
- 同一位置有多张图时，各图工具按图片序号分组，收藏和编辑分别作用于对应图片。
- 首次生成的入口、生图进度、取消和失败恢复仍直接显示，重画时旧图继续保留。
- 支持手机窄屏和键盘展开，入口图标颜色跟随人物主题。

完整操作见 [聊天图片快捷操作](../chat-assistant.md#聊天图片快捷操作)。

## 画风参考编码

每张参考图分别显示「未编码」「正在编码」「已编码」「编码失败」或「待重新编码」。编码失败时，原因显示在对应图片下方，可单独点击「重试编码」；重编失败不会删除已有的成功编码。

修改模型或信息提取量后，可直接查看是否需要重新编码。调整提取量只更新对应条目的状态，保留输入焦点。NovelAI V3 按其规则显示「无需编码」。

普通图片上传、编码文件导入和保存复用见 [氛围转移教程](../novelai-vibe.md)。编码与生图分别请求，均可能按服务规则计费；插件不会自动重试编码。

## 更新方法

更新插件后刷新酒馆一次，在「更新日志」核对版本 **0.26.11**。本版无需重新填写 API、清空图片或重启酒馆。

已通过 726 项自动测试，以及 320、390、768、1280 像素宽度的隔离浏览器回归。验证覆盖按钮操作、版本切换、主题切换、状态保留、生成取消、失败恢复及逐图编码状态；未调用付费编码或生图接口。
