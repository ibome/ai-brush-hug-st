# 灵画师 0.26.17

2026-11-22。修复酒馆创建聊天分支后，历史楼层已经画好的图变回「生成图片」的问题。

## 分支聊天配图

1. 在酒馆扩展管理更新灵画师，然后刷新酒馆。
2. 打开之前创建的分支，也可以从楼层菜单新建分支。只要分支保留酒馆记录的来源，且原图仍能读取，插件就会在对应楼层显示配图。
3. 切换回复版本时，按当前版本匹配配图。需要为当前分支画一张新图时，打开「图片操作」，点击「在此分支生图」。

「图文阅读」和导出使用相同的匹配方式。使用浏览器存图时，请在保存原图的浏览器和站点打开分支。通过文件导入恢复的聊天也需要保留分支来源信息才能匹配。

发布前覆盖了分支和嵌套分支匹配、回复版本隔离、图文读取及导出，并在内置浏览器的模拟酒馆验证旧图加载和分支内单独生图。
