# 灵画师 0.23.3

修正官方 NovelAI 连接测试及设备网络诊断中的误报。

- 官方连接测试与诊断订阅检查统一使用 `image.novelai.net/user/subscription`，与图片请求使用同一服务域名。依据 [官方图片 API 文档](https://image.novelai.net/docs/index.html)，避免仅旧账号域名不可访问时阻断连接测试。
- 不透明辅助请求改用浏览器支持的重定向模式，避免请求尚未发出就失败；辅助响应仍不能确认真实 HTTP 状态、鉴权或生图权限。
- 手机本地酒馆地址不再误触发生图接口的本机地址提示，修正官方 Bearer 认证方式显示及地址重复脱敏。
- 当图片首页已响应但订阅路径失败时，提供更具体的路径排查提示。

遇到 0.23.2 日志中账号域名失败、图片域名可达的用户，请更新并刷新酒馆，再测试连接。若仍失败，在原设备重新运行检测并复制新日志。此次更新不能代替设备代理、服务跨域或访问限制的配置。

服务器组件保持 0.21.0／协议 2，无需重装组件或重启酒馆。
