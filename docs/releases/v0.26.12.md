# 灵画师 0.26.12

本版修复秘钥存储失败导致接口预设无法保存、聊天生图被阻断的问题。前端构建标识为 `20261113-credential-storage`，可选服务器组件保持 **0.21.2 / 协议 2**。

## 秘钥保存

- 酒馆允许读取秘钥且接口可用时，继续保存到当前酒馆账号。
- 酒馆秘钥接口不可用时，新填写的秘钥改为本机保存；浏览器设置缓存写满、受限、损坏或未实际写入时，自动尝试当前账号的独立数据库。
- 写入后重新读取确认，成功时显示「秘钥已保存在酒馆账号」或「秘钥已保存在当前浏览器」。
- 两种本机存储都不可用时，明确提示空间、权限或超时等原因，保留本次输入供重试，不会把未持久化的秘钥标记为已保存。
- 旧秘钥引用与预设继续兼容，各账号和接口的秘钥分别读取；提示词助手保存失败时保留输入焦点，重试成功后更新状态。

## 遇到旧版保存失败

更新后刷新酒馆，到「接口配置」重新填写一次未能保存的秘钥，等待出现「秘钥已保存…」，再保存接口或参数预设。该报错来自存储环节，不能据此判断服务商 Key 无效。

本机保存需使用同一浏览器、酒馆地址和账号；换设备请使用包含秘钥的加密备份。不要直接清空站点数据。仍失败时，到「调试工具」检测存储与缓存，反馈脱敏日志。详见 [秘钥保存与排错](../interfaces.md#秘钥保存位置与失败处理)。

## 更新方法与验证

更新插件后刷新酒馆一次，在「更新日志」核对版本 **0.26.12**。无需重启酒馆或重新安装服务器组件。

已通过 734 项自动测试、8 组隔离浏览器场景及正式构建。浏览器验证覆盖缓存写满、存储权限受限、缓存损坏、写入被丢弃、酒馆秘钥接口不可用、全部存储不可用、助手保存与重试恢复；包含刷新读取、旧预设切回、账号和接口隔离，以及 320、390、768、1280 像素宽度。未调用付费生图接口。
