# 灵画师 0.26.6

2026-11-04 发布。修复手机通过局域网访问电脑酒馆时，生成请求已经完成、图片已保存，但当前页面没有及时显示进度或图片的问题。

## 手机生图及时显示结果

点击「生成图像」会立即显示准备或排队状态，提交期间短暂防止重复点击。完成保存后，聊天配图、生图工坊结果和图库数量自动更新。

后台任务查询暂时失败时，当前页面已收到的进度和图片仍会继续显示。已完成配图不再被旧的「执行中」记录遮住，聊天图片缓存也会随任务记录及时更新。

若图片已经保存、图库索引稍晚才可读取，插件会按已完成任务的图片编号有限补查，不会因此重新发送生图请求。

## 返回页面后自动补查

手机切回浏览器、网络恢复，或通过浏览器返回缓存页面时，会恢复任务查询和图片通知，补查已保存的结果。后台任务完成后，无需为查看图片再次点击生成。

进度与结果采用局部刷新，保留正在输入的提示词、输入焦点与键盘状态。

## 更新方法

1. 等待正在执行的任务结束，在「更新日志 → 版本与更新」或酒馆扩展列表更新。
2. 更新后刷新酒馆一次，载入新版代码；之后正常生成和查看结果不需要反复整页刷新。
3. ZIP 安装用户使用 `ai-brush-hug-st-v0.26.6.zip` 覆盖插件代码后刷新。

本次仅更新前端。可选服务器组件仍为 **0.21.2／协议 2**，已安装该版本的用户无需重复更新组件或重启酒馆。更新保留接口配置、秘钥、已保存图片与任务记录。

已完成 696 项自动化测试，以及普通局域网 HTTP、手机尺寸视口和后台任务查询失败场景的浏览器回归；尚未在反馈用户的手机硬件上验证。
