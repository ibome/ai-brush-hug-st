# 灵画师 v0.24.0

本版修复普通 HTTP 酒馆的加密接口兼容问题，增加侧边栏「调试工具」，并减少图库重复写入。

- 普通 HTTP 环境通过安全随机数生成 UUID，并兼容 SHA-256 图片校验，修复插件启动白屏和相关存图失败。加密备份仍需 HTTPS 或本机安全环境。
- 网络检测统一从调试工具进入，可独立选择四种接口。
- 新增设置缓存、图片数据库读写、站点容量估计、当前账号记录数量、酒馆目录和页面响应采样。
- 最近失败记录显示具体阶段与原因，支持复制和下载脱敏综合日志，不自动发送。
- 新增、切换图片版本、删除和自动清理只写实际变化记录，减少已有图片重复写入。

请通过酒馆扩展更新或「更新日志 → 立即更新」升级后刷新。服务器增强组件仍为 0.21.0／协议 2，无需为本版重装。

遇到生成或保存失败时，先在当前页面完成检测再复制日志；已有响应可尝试继续取图或保存。工具不清空用户缓存或图片，容量估计也不能反映酒馆服务器磁盘。

操作步骤见 [调试工具](../debug-tools.md)。
