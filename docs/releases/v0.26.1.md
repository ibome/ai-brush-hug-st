# 灵画师 0.26.1

修复接口地址改正后，聊天中之前失败的配图无法重新生成的问题。

## 更新后怎么操作

1. 在酒馆更新灵画师并刷新页面。
2. 在“接口配置”中确认当前地址与秘钥已修正。
3. 回到聊天里原来失败的配图，点击“重新生成”并确认。新任务使用当前接口配置；智能配图会复用之前分析好的提示词，也可以先编辑提示词。

旧版本会把接口返回的错误 JSON 也缓存成可取回的结果，导致“继续取图”反复解析同一份错误响应。本次更新兼容这些旧失败记录，无需删除聊天或清空缓存。

## 两个操作的区别

- **继续取图 / 保存**：适用于服务已返回图片或有效图片地址，但下载或存储失败的任务；继续取回已有结果，不重新提交生图请求。
- **重新生成**：用当前接口配置创建新任务，保留原消息的配图位置；属于新的生图请求，可能再次计费，操作前会提示确认。

同时修复无效响应阻止聊天图片“再画一张”的问题，并统一任务列表、恢复操作和扩展接口的可恢复状态判断。服务器组件无需更新。
