# 灵画师 0.26.10

本版修复 NovelAI 画风参考的编码失败问题，并优化手机操作。前端构建标识为 `20261112-vibe-encoding`，可选服务器组件保持 **0.21.2 / 协议 2**。

## 更新内容

- 修复 `sk-` 秘钥自动识别出蛋糕或砂糖服务后，编码流程仍误判失败并显示「操作失败，请重试」的问题。
- 参考条目增加带图标的「编码参考图」文字按钮，手机上可以直接找到入口。
- 点击后立即显示「正在编码…」，处理期间阻止重复提交；成功后显示「当前模型可用」，修改信息提取量后会提示重新编码。
- 错误提示区分鉴权、权限、接口不支持、频率或额度、服务异常、网络连接和超时，方便定位问题。
- 同步更新 [氛围转移图文教程](../novelai-vibe.md) 与流程图，说明普通图片上传、编码文件导入、提取量和保存复用的方法。

## 使用方法

1. 在「接口配置」配置好 NovelAI 模式的秘钥与模型。
2. 打开「生图工坊 → 高级生图 → 参考生图」，参考用途选「画风参考 · Vibe」。
3. 普通图片点「添加画风参考」，再点条目下方的「编码参考图」；已有 `.naiv4vibe` 文件则直接导入。
4. 等条目显示「当前模型可用」，填写画面提示词，再点「生成图像」。

编码与生图分别请求，均可能按服务规则计费。插件不会自动重试编码。普通生图、模型列表或只读网络检测成功，不能证明服务支持 Vibe 编码。

TauriTavern 仍使用当前设备的 WebView 访问外部生图接口；本次修复不会改变代理方式或补齐第三方服务缺失的编码能力。

## 更新方法

更新插件后刷新酒馆一次，在「更新日志」核对版本 **0.26.10**。无需重新填写 API、清空图片或重启酒馆。

本版通过 721 项自动测试，以及 320、390、768、1280 像素宽度下的隔离界面回归；验证未调用付费编码或绘图接口。
