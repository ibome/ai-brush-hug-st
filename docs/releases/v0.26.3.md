# 灵画师 0.26.3

2026-11-01 发布。附带作者在酒馆使用的生图世界书，补齐第一次聊天生图的步骤；新增保留 API 的分项重置，修复聊天重画未采用当前画风，并完善服务器任务锁续期。

## 新人直接聊天生图

1. 安装灵画师，刷新酒馆。
2. [下载生图世界书 JSON](https://raw.githubusercontent.com/ibome/ai-brush-hug-st/main/docs/worldbooks/-%20%28%E4%B8%BB%E4%BD%93%29%E6%96%87%E7%94%9F%E5%9B%BE1.17.json)，在酒馆「世界书 / 世界信息」中导入。
3. 绑定当前角色，或启用为当前聊天使用的全局世界书。仅导入但没有启用，不会参与聊天。
4. 在灵画师配置自己的图片接口、秘钥和图片模型，测试连接；推荐先手动成功生成一张图。
5. 保持默认开启的「自动生图」「在聊天中显示图片」，正常发送聊天，等待新角色回复完成。回复出现可识别的画面提示词后，插件会自动排队并在聊天中出图。

世界书文件名为 **- (主体)文生图1.17.json**，按原文件上传，全部内容和字节保持不变。前端安装 ZIP 的 `docs/worldbooks/` 也包含原文件。世界书提供聊天生图约定，实际输出仍取决于所用文字模型。

「提示词助手 → 参考世界书」是另一个功能，控制助手分析是否额外读取世界书，新安装默认关闭；正常聊天标签生图不需要为此打开助手开关。

## 设置填乱了怎么恢复

打开「插件设置 → 重置设置」，选择范围并确认：

| 范围 | 恢复内容 |
| --- | --- |
| 常规设置 | 自动生图、聊天展示、触发格式、任务调度与清理开关 |
| 当前生图参数 | 当前模式的提示词、画师串、尺寸、采样及高级生图状态 |
| 提示词助手设置与底层提示词 | 助手规则、前置词、插入模板、自动配图设置及未保存规则草稿 |

默认勾选前两项，助手规则默认不勾选。保留所有 API 地址、秘钥、认证方式、模型和连接兼容参数，也保留主题、存储位置、图片、任务、角色、画师库与预设库。ComfyUI 的工作流、映射、Checkpoint 和 VAE 保留。任务执行期间需先等待完成。

## 当前画风与默认画风

- 聊天「再画一张」保留原场景、模型、尺寸与工作流，应用原生图模式当前的画师串和负面提示词，以新随机种子创建新版本。
- 已有图片与历史参数保持原样；想固定旧风格，可从历史参数另行发起生成。
- 首次安装 NovelAI 使用作者设置的默认画师串和负面词；升级不覆盖个人设置，包括主动清空的字段。
- 需要恢复这套默认画风时，可载入默认配置，或重置当前生图参数。助手「参考世界书」升级时也保留原选择。

## 更新与验证

前端更新到 0.26.3 后刷新酒馆。可选 `linghuashi-storage` 组件更新为 **0.21.1／协议 2**，修复慢请求提交时后台计时暂停导致执行锁过早失效的问题。使用旧组件且需要此修复时，由管理员更新服务器 ZIP 并重启酒馆；普通账号存图无需安装组件。

发布前运行完整自动化测试、生产构建与打包检查。世界书仅核对原文件、仓库副本和安装包副本的字节校验，不解析或改写正文。此前已检查重置对话框的电脑与手机排版，没有执行当前账号的真实重置，也没有为本次发布额外提交付费生成请求。
