# 灵画师 0.26.2

2026-11-01 发布。新增可切换的聊天插入模板，完善提示词编辑保存，修复手机接口输入中断与聊天图片模糊，并更新新漫画的默认统一提示词。

## 聊天插入模板

进入「提示词助手 → 查看 / 编辑底层提示词」，任务选择「聊天配图」。插入模板提供：

| 模板 | 用途 |
| --- | --- |
| 默认 · 标签插入 | 通用画面规划与标签输出。 |
| 大鲸鱼国模预设 | 中文任务约束。 |
| 自然语言智能插入 | 完整英文句子，适合自然语言图片模型。 |
| English Unbound | 另一组英文视觉任务规则。 |
| 翻译官 · 实测四模型 | 中文场景转英文 Danbooru 标签，并附输入输出示例。 |

1. 选择模板，查看载入的规则；可继续编辑前置要求和正文。
2. 点击「预览展开结果」，检查实际消息和动态内容；此步骤不调用模型。
3. 点击「保存本任务」后生效。

直接关闭只保留本设备草稿；「丢弃未保存草稿」恢复当前生效内容。保存其他任务不会误应用尚未保存的聊天模板。翻译官示例只出现在聊天配图请求中。

已有自定义规则会保留且正文优先。希望改用内置正文时，重新选模板或恢复本任务默认，再核对保存。顶部「日常配图／人物特写／多图剧情」控制构图、画幅与张数；聊天插入模板控制底层规则，两者分别配置。模板不会自动关闭酒馆预设，也不保证每个模型都按相同方式理解请求。

## 配图与漫画规则

优化关键事件顺序、人物外貌与服装延续、道具归属、原文定位和多画面内容区分。漫画分镜补充剧情开头到结尾的覆盖、单格可见状态、镜头选择、对白说话人与原文顺序要求。

新建漫画项目的统一正向词：

```text
masterpiece, best quality, very aesthetic, absurdres, newest, anime comic illustration, clean line art, soft cel shading, sharp outlines, detailed eyes, soft lighting, vibrant color, clean coloring
```

统一负面词：

```text
lowres, worst quality, low quality, normal quality, bad anatomy, bad hands, missing fingers, extra fingers, fused fingers, extra limbs, missing limbs, bad feet, deformed, disfigured, mutation, blurry, jpeg artifacts, signature, watermark, username, text, error, cropped, poorly drawn face, cross-eyed, bad proportions, ugly, 3d, render, photorealistic
```

统一画风和负面词参与各画格的图片请求；分镜底层规则用于文字模型规划，二者分别编辑。已有漫画项目和个人自定义任务规则不自动覆盖。提交前可核对逐格实际正负词。
