# 灵画师 0.26.18

2026-11-26。修复切换参数预设时，因预设关联的秘钥无法读取而跳回原预设的问题。

## 切换参数预设

1. 在酒馆「扩展管理」更新灵画师，然后刷新页面。
2. 进入「接口配置」或「生图工坊」，从「参数预设」选择想用的预设。
3. 如果预设关联的秘钥在当前酒馆账号或浏览器中无法读取，插件仍会载入模型、提示词等绘图参数，并使用当前配置中的接口和秘钥。提交生图前可在「接口配置」确认当前使用的服务。
4. 多个预设共用同一个生图接口时，在「预设关联接口」选择「仅保存参数 · 保留当前接口」，然后点「保存预设」。切换这些预设时会直接沿用当时使用的接口。

本次修复覆盖 NovelAI、OpenAI 兼容、ComfyUI 和 SDWebUI。可选服务器组件仍为 0.21.3，存储协议仍为 2。
