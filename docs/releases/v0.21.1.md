# 灵画师 0.21.1

本次将服务器上已完成的 0.12.0 至 0.21.1 功能同步到 GitHub，并补齐分功能教程。完整记录见仓库 `CHANGELOG.md`。

## 从 0.11.1 升级可获得

- 中文标签库、双栏组合、素材卡、可视化提示词、组合生图和画风探索。
- AI 创建角色档案、逐字段对比更新，保留原有角色绑定、服装及聊天覆盖。
- NovelAI 高清放大、细节增强与导演工具。
- 聊天「给这条配图」、再画一张、改本图提示词、收藏、下载和更多编辑操作。
- 九套人物主题的透明奔跑等待状态，Gemini 使用薄荷绿形象。
- 面向其他扩展的生图 API v1、来源标记、请求去重和持久化结果查询。
- SDWebUI 第四种原生模式，包含 LoRA、高清修复、图生图、局部重绘及 extras 放大。
- 侧边栏更新日志与完整分功能教程，支持离线查看版本记录。

## 安装与升级

1. 等待正在执行的任务结束。
2. 在「插件设置 → 备份与迁移」导出个人备份；需要带走秘钥时选择加密。
3. 已从仓库安装的用户，通过酒馆扩展管理更新并刷新；手动安装可使用前端 ZIP。
4. 从 0.11.1 等旧版升级的管理员，更新配套 `linghuashi-storage` 组件并重启酒馆，保留自己的 `allowed-accounts.json`。
5. 已在服务器使用 0.21.0 组件的用户，本次无需因文档及日志更新再次替换组件或重启。

前端版本为 0.21.1；配套服务器组件自身版本为 0.21.0，协议 2。服务器 ZIP 以本次发行版本命名。
