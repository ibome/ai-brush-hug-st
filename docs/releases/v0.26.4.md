# 灵画师 0.26.4

2026-11-02 发布。修复聊天图片的待核对任务导致重画按钮一直不可用，并让插件主开关与悬浮球分别控制。

## 聊天图片可以继续重画

上一项请求显示「结果待核对」时，服务端可能已经接收请求，但插件尚未确认最终结果。现在「再画一张」和「修改提示词」可以继续使用：

1. 先查看图片服务的任务或用量记录。
2. 点击「再画一张」，或修改本图提示词后提交。
3. 阅读可能再次计费的提示。确认后才会创建新的生图任务；取消不会提交。
4. 原待核对记录保留，新任务成功后生成图片的新版本。

插件不会自动重试待核对请求。正在等待、准备、执行、暂停，或仍能继续取图／保存的失败任务，继续按原流程处理。已接收结果但下载或保存失败时，优先继续保存现有结果。

聊天重画沿用 0.26.3 的行为：保留原图场景、模型、尺寸与工作流，应用来源模式当前的画师串、负面提示词和接口凭据。

## 关闭生图后保留悬浮入口

| 设置 | 控制内容 |
| --- | --- |
| 插件开关 | 是否接收和处理新的生图操作。 |
| 显示悬浮球 | 是否显示酒馆页面上的人物入口。 |

关闭插件时，只要「显示悬浮球」保持开启，仍可点击人物图标进入设置。关闭悬浮球后，可从酒馆「扩展」中的灵画师入口打开设置。开关选择会保存，切换主开关不会覆盖悬浮球的选择。

## 更新方法

Git 安装可在灵画师「更新日志 → 版本与更新」或酒馆扩展列表更新，完成后刷新酒馆。ZIP 安装使用前端安装包覆盖插件文件后刷新。

这次只更新前端，服务器组件保持 0.21.1／协议 2，无需重新安装组件。更新不清空接口、秘钥、图片、任务或个人设置。
