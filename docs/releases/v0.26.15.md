# 灵画师 0.26.15

2026-11-18。新增按画面管理多角色、站位与互动，完善新人创建档案和旧图人物编辑流程。

## 第一次使用多角色

1. 在“角色档案”创建人物，填写固定外貌和服装。其他称呼可填到“人物别名”，用 `|` 分隔。
2. 点击“保存并加入出场”。只想先存入素材库时使用“仅保存档案”。
3. 在生图工坊的“出场人物”选择本图人物，设置动作、表情和服装。
4. 点“并排站位”，或在 5×5 位置网格中指定位置。A3 为左侧中部，E3 为右侧中部。
5. 需要互动时选择目标人物并填写动作。对方未出场时会提示，该互动不会提交。
6. 打开“预览本次生图”，核对实际正负词、人物分栏与坐标，再提交图片生成。

没有角色档案时，工坊提供直接创建和 AI 创建入口。AI 创建需要文字接口；手动创建、调整位置和本地预览不调用模型。未保存修改与删除确认使用主题内窗口，默认保留当前编辑。

完整说明见[多角色模式教程](https://github.com/ibome/ai-brush-hug-st/blob/main/docs/multi-character.md)。

## 聊天与漫画

“随剧情出场”允许助手按画面筛选人物；“固定出场”要求助手保留该角色。直接手动生图且没有助手或分段提示词时，使用已勾选的全部人物。

聊天提示词支持公共场景与分角色段落，分别填写人物正负词、动作、表情、服装和坐标。名称与别名按完整名称或标签匹配；歧义角色保留为本图临时人物并提示，不自动改写档案库。普通提示词继续使用原流程，无需修改已有世界书。

漫画每格可以独立选择人物、覆盖站位和互动。未指定时跟随项目配置，不会因为调整一格而修改全局档案。

NovelAI 使用模型支持的原生角色参数。通用图片接口会整理成文字描述；OpenAI 兼容的两种独立角色格式需用户确认服务支持后手动选择，不自动尝试不同格式或重复请求。

## 旧图片与重新生成

从图库载入图片参数后，人物配置与档案库独立。即使档案已删除，仍可调整原图人物的动作、位置、互动和出场名单。明确取消全部人物后，不会自动补回当前档案库中的人物。

聊天图片现在提供三种方式：

| 操作 | 画风与人物来源 |
| --- | --- |
| 再画一张 | 当前预设画风，沿用原图人物与动作 |
| 沿用原图画风再画一张 | 沿用原图画风及人物记录 |
| 使用当前档案与画风再画 | 当前画风，按原图人物 ID 更新当前档案外貌与服装，保留本图动作和位置 |

历史图片继续保留各自快照。旧记录没有分项动作时，只能恢复可识别部分，复杂动作可手动补充。

## 服务器组件与更新

前端更新到 0.26.15 后刷新酒馆一次，保留已有配置、秘钥、档案与图片。

可选 `linghuashi-storage` 组件更新为 **0.21.3／协议 2**：

- 助手草稿归档和备份保留每幅画面的人物名单、位置及互动。
- 组件 ZIP 和安装脚本完整包含助手草稿依赖，修复新安装缺少模块的问题。

使用该组件的管理员应先等待任务结束，备份后覆盖组件代码，保留 `allowed-accounts.json` 与账号数据，再重启酒馆。下载包名称跟随前端发行版本，组件页面应显示内部版本 0.21.3。普通酒馆账号存图无需安装组件，TauriTavern 继续使用宿主内置存图。
