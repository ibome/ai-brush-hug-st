# 字段格式与触发词

入口为侧边栏「提示词处理」，生图工坊也有「字段与触发词」快捷入口。

本文对应 0.26.16 正式版（2026-11-19）。第一次使用多角色可先看[多角色新手教程](multi-character.md)。

## 选择多角色字段方案

默认「自动兼容」同时识别原有英文、中文和短格式。无需为了已有世界书修改方案。

短格式示例：

```text
Scene: 2girls, cafe
Char1: blue hair, blue eyes, waving |centers:B3
Char1 UC: red hair
Char2: green hair, reading |centers:D3
Negative: blurry, lowres
```

标准格式仍使用 `Scene Composition:`、`Character 1 Prompt:`、`Character 1 UC:` 和 `Negative prompt:`。

需要精确限定一种格式时，选择对应方案并点「保存字段方案」。自定义方案可改四种字段头：公共场景、人物正向、人物负面和全局负面。人物字段中保留一个 `{n}`，代表角色编号；还可以包含一个 `{coord}`，例如 `Person{n} ({coord}):` 对应 `Person1 (B3):`。字段头以冒号结尾。`Character 1 Name:`、`Action:` 等人物元数据继续兼容。

分段后的每个人物分别提交正负词；能否使用原生角色坐标，仍由图片模型与接口格式决定。选择字段方案不会修改世界书。

## 添加触发词

自动替换默认关闭，先添加规则，再开启「生图前自动替换触发词」。

1. 在触发词填写 `爱丽丝 | alice`。
2. 替换内容填写 `blonde hair, blue eyes, white dress`。
3. 选择全部提示词、仅正向、仅负面或仅画师串。
4. 点「添加规则」。
5. 到生图工坊填写 `1girl, 爱丽丝, garden`，回到本页点「预览替换结果」，或点生图工坊的「预览本次生图」。

预览会显示命中的词、来源、替换内容和实际提示词，不提交生图请求。规则可以逐条关闭、编辑或删除；人物独立提示词也参与相同处理。已有图片不会被修改。

修改规则后重画，未手动修改的字段会从原始触发词按当前规则重新展开；手动编辑过的字段保留编辑值，再按当前规则处理。关闭替换后重画会恢复未改动字段的原始词语。

按完整标签或词语边界匹配，不把 `alice` 匹配到 `malice`，也不把「蓝」匹配到「蓝天」。替换只执行一轮，规则输出不会继续触发其他规则；`<lora:...>` 等尖括号语法保留。需要替换一句话里的特定内容时，请将它单独写成标签或设置完整词语。

## 数据源与优先级

- 自定义规则：手动添加的映射。
- JSON 规则：从文件导入的映射。
- 本图人物档案：只从本图出场人物读取名字、别名及当前外貌服装，不扫描其他聊天的人物。
- 中文标签库：把库中中文名称和含中文的别名转为英文词。

自动来源需要单独勾选。优先级为「自定义 → JSON → 本图人物档案 → 中文标签库」。同一优先级出现一个词对应多个不同结果时，保留原词，并在实际命中时提示冲突。

## JSON 导入导出与备份

支持灵画师导出格式、规则数组，以及简单词语映射。不保证兼容其他插件所有私有格式。

```json
[
  { "trigger": "蓝发|蓝色头发", "replacement": "blue hair", "target": "positive" },
  { "trigger": "模糊", "replacement": "blurry", "target": "negative" }
]
```

也可以写成：

```json
{ "蓝发": "blue hair", "模糊": "blurry" }
```

最多 500 条规则、200 KB；每条最多 16 个别名，替换内容最多 4000 字符。导入失败不会只保存一半规则，重复内容不会反复加入。

配置备份的「中文标签库」分区同时携带字段方案与触发词。覆盖恢复使用备份设置；合并恢复只合并规则，保留当前开关和字段选择。「重置常规设置」关闭替换并恢复自动兼容字段，保留已保存规则和接口秘钥。

## Decrisper

NovelAI 模式在「生图工坊 → NovelAI 参数 → 其他参数设置」提供开关，默认关闭。设置随参数预设和图片参数保存；导入带 `dynamic_thresholding` 元数据的 NovelAI PNG 时也能读取。

OpenAI 兼容模式只有模型名包含 `nai-diffusion` 时显示。仅在服务方支持 `dynamic_thresholding` 参数时开启；关闭时不额外向通用接口发送此参数。附加 JSON 已填写相同参数时会提示冲突，不会悄悄覆盖。

它用于调整高 CFG 下的画面表现，不保证提升人物或构图准确度。保持关闭即可沿用原有行为。
