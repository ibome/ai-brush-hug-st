# 绘图管理、存储与任务

[返回教程目录](../README.md)

## 查找与查看作品

入口：「绘图管理」。先核对「插件设置」中的存储位置；浏览器库和服务器库分别显示。

1. 按来源模式、日期、聊天归档和筛图分类过滤。
2. 点击缩略图打开大图，查看正负提示词、画师、模型、种子、尺寸与历史版本。
3. 收藏重要作品，或下载原图。
4. 需要复用时，点击「导入并覆盖来源模式参数」，载入对应模式的配置。

参数回填会改变当前配置，适合在工坊继续绘图。只想调整某张图时，用「编辑这张图」保持全局参数不变。导入的外部图片只有包含可识别参数时才能完整回填；缺失内容不会凭空还原。

## 单图编辑与历史版本

1. 大图详情中点「编辑这张图」。
2. 在独立草稿里修改提示词、角色快照、模型或尺寸等。
3. 可用助手改词，或选择以该图继续画、局部重绘、图片增强。
4. 点击「重绘为新版本」，等待任务完成。
5. 新结果成为该图组当前版本，旧版本保留；聊天原图片位置同步显示当前版本。

从旧版本也可继续分支；可设为当前版本、双图比较、复制种子、收藏和删除单个版本。删除当前版本会选用最新剩余版本。删除整个图组与删除一个版本是不同操作。

重绘使用来源模式的当前接口凭据，而非从图片文件恢复旧 Key。ComfyUI 沿用原工作流，只改已映射参数，复杂多输出以配置的输出节点为准。

## 快速筛图

点击「快速筛图」后，可用按钮或快捷键分类：

| 键 | 分类 |
| --- | --- |
| 0 | 未分类 |
| 1 | 精品 |
| 2 | 可用 |
| 3 | 淘汰 |
| 左右方向键 | 前后图片 |
| Z | 撤销上一项标记 |

标记后自动前进，最后一张停留。淘汰只做标记，不删除图片。分类按版本及存储位置保存，配置备份可以携带，分享包不包含个人筛图记录。

## 图片导入导出

1. 点击「导入」选择支持的图片或灵画师图片包，核对可读取的参数。
2. 导出前用筛选或多选确定范围。
3. 选文件命名：序号加名称、种子或模型。
4. PNG 元数据可保留原有、移除文本与 EXIF，或写入灵画师参数。
5. 点击「导出」获取 ZIP，也可以直接下载图片。

导出不会改图库原图；非 PNG 保持原文件。批量操作以图组为单位时包含选中图组的历史版本，删除前核对按钮显示的范围。

## 浏览器与酒馆服务器

| 对比 | 浏览器 | 酒馆服务器 |
| --- | --- | --- |
| 位置 | 当前账号在当前浏览器的站点存储 | 当前登录账号的服务器图片目录 |
| 换设备 | 不自动共享 | 同账号可读取 |
| 主要容量限制 | 浏览器可用空间与配额 | 服务器磁盘及管理员配置 |
| 服务器组件 | 无需安装；任务可在此浏览器恢复 | 普通存图无需安装；跨设备任务恢复可选增强组件 |

服务器原图保存在账号的 `user/images/linghuashi`，缩略图在 `user/images/linghuashi-thumbnails`，参数、聊天关联和参考素材在 `user/files/linghuashi-*`。已有增强组件的旧目录继续读取。文件按当前账号隔离，服务器存图不是把文件放到浏览器所在电脑。

切换位置不会自动迁移旧作品。服务器存储页提供「检查存储」和「迁移浏览器图片」，迁移前先导出备份，完成后核对数量和历史版本。

自动清理跳过受收藏和聊天关联保护的图组。浏览器库和内置账号存储需页面运行才能执行清理；增强组件可在后台清理其管理的作品。检查存储发现的无参数文件不会擅自删除，避免中断保存时丢失图片，可在原设备继续保存任务。

## 持久化任务与恢复

任务区域显示等待、执行阶段、完成、失败、取消或结果待核对。任务记录保存计划、已提交状态和可恢复结果，让刷新后有据可查；**不是关闭网页后所有接口都能无人值守完成。**

没有增强组件时，任务记录和已接收响应保存在当前账号的浏览器 IndexedDB。刷新同一浏览器可恢复，换设备只能读取已保存到账号的作品与参数；清除站点数据会删除此设备的任务记录。多标签页在浏览器支持 Web Locks 时共用执行锁；跨设备同时执行需服务器增强组件。后来安装组件后，此浏览器旧任务仍会显示并按原位置处理，新任务使用增强组件。

| 刷新后状态 | 该怎么做 |
| --- | --- |
| 尚未提交／暂停等待 | 核对后手动继续，避免意外消耗额度。 |
| 已返回结果，尚未保存 | 继续取图或保存现有响应，不重新提交生图。 |
| ComfyUI 已有远程任务编号 | 在服务允许且记录完整时继续查询结果。 |
| 请求已发出，无法确认远程结果 | 先查看服务记录，再决定是否重新生成。 |
| 已完成 | 到绘图管理查看，不需要再画一次。 |

不要用反复点击生成来处理未知状态。重新提交可能再次计费，界面会提示相关风险。

聊天图片的「结果待核对」记录不会一直禁用「再画一张」和「修改提示词」。核对服务端记录后，可点击操作并确认再次提交；新任务与原记录分开保留。已收到结果但下载或保存失败时，应优先使用「继续取图或保存」。

取消尚未提交任务可以阻止请求；已提交任务按服务能力停止等待或取消排队。SDWebUI 不发送会影响其他人的全局中断，取消本地等待不代表远程一定停下。

聊天任务还绑定会话、消息内容和回复分支；原消息变化时，未提交请求会停止，已生成作品仍保留。

## 备份与迁移的边界

任务在备份里作为归档保存，恢复不会自动加入执行队列。聊天正文、角色卡文件、远程运行状态和未保存的远程响应不随作品包搬迁。换设备前阅读 [备份与恢复](backup.md)。
