## 第一次聊天生图

1. 安装灵画师并刷新酒馆。
2. 在酒馆的「世界书 / 世界信息」中导入这个 JSON 文件。
3. 将导入的世界书启用于当前聊天，例如绑定当前角色，或选为当前使用的全局世界书。只导入文件、没有启用，不会参与聊天。
4. 在灵画师中选择生图模式，填写自己的图片 API、秘钥及模型，测试连接；建议先手动成功生成一张图片。
5. 保持「自动生图」和「在聊天中显示图片」开启，两项为新安装默认值；「生成前确认提示词」默认关闭。
6. 正常发送聊天，等待角色新回复完整结束。回复包含符合插件触发格式的画面提示词时，插件自动排队生图，并在聊天里显示结果。

文字聊天接口和图片生成接口各自需要可用。世界书用于向聊天模型提供生图约定；实际输出仍由聊天模型决定。没有出现图片时，先核对世界书是否启用、回复中是否有可识别的提示词，再到灵画师查看任务错误。

**这与提示词助手中的「参考世界书」开关不同。** 该开关控制助手分析时是否额外读取世界书，默认关闭；不影响已启用的世界书参与酒馆正常聊天，也不是标签自动生图的必开项。
