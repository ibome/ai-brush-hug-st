# 安装、更新和回退

## 前端

在 SillyTavern 扩展管理中安装仓库 `https://github.com/ibome/ai-brush-hug-st`。仓库根目录含 `manifest.json`，入口为 `dist/index.js`，无需编译。

希望全部账号使用时由管理员选择所有用户安装；希望仅一个账号使用时安装到该账号。账号间设置、秘钥和图片保持独立。

## 可选服务器增强组件

TauriTavern 用户请参考 [专用说明](tauritavern.md)。该客户端使用内置本机存图，不安装下述 Node 服务器组件；公开 TestFlight 默认策略可能禁用第三方扩展。

普通存图无需安装服务器组件，直接在「插件设置」选择「酒馆服务器」即可。侧边栏「扩展组件」提供状态检测、下载和安装步骤。需要跨设备任务恢复、服务器执行锁及后台清理时，再由管理员安装以下组件。

下载 Releases 中独立的服务器 ZIP，解压至：

```text
SillyTavern/
  plugins/
    linghuashi-storage/
      index.mjs
      task-ledger.mjs
      image-versions.mjs
      reference-assets.mjs
      reference-actions.mjs
      backup-records.mjs
```

也可从源码目录执行：

```sh
node scripts/install-server.mjs --st-root /绝对路径/SillyTavern
```

脚本会备份已有模块后更新，保留已有 `allowed-accounts.json`。在酒馆 `config.yaml` 中设置 `enableServerPlugins: true` 后，使用自己的启动方式重启酒馆。

宝塔用户可在文件管理中解压 ZIP，再在配置编辑器启用该选项；通过自己的 PM2、systemd 或 Node 项目管理入口重启。

没有启用组件时仍可使用内置账号存图，任务记录在此浏览器恢复。酒馆的前端扩展安装入口不能安装服务器组件。接口的跨域限制、反向代理鉴权和 ComfyUI 节点仍由使用者的服务配置决定。

## 更新

1. 等待当前生图和助手任务结束。
2. 导出个人配置备份，需要搬迁图片时导出完整备份。
3. 到「更新日志 → 版本与更新」点击「立即更新」。Git 安装通过酒馆原生接口拉取，ZIP 安装下载新版前端 ZIP 手动覆盖；服务器组件有变化或当前组件过旧时，安装本次配套的服务器 ZIP。
4. 前端更新后点击「刷新酒馆以生效」；更新过服务器组件时还需重启酒馆，通过「更新日志 → 版本与更新」核对版本与协议。

当前前端为 **0.25.0**，可选服务器组件自身为 **0.21.0／协议 2**。服务器 ZIP 按发行版本命名，内部组件仍显示 0.21.0。已安装兼容组件时，本次前端更新无需重启。

新内容使用许可、旧版 BSD 权利与第三方声明见 [使用与署名说明](usage-license.md)。

进入酒馆后会自动检查 GitHub 正式发布版本。发现新版时，扩展列表「灵画师」旁显示「有更新」和版本号，透明 Q 版人物喊「插件更新啦！」，人物与气泡跟随当前主题。点击打开更新日志中的更新面板；关闭后同一版本不会反复出现，但列表标记保留。只有手动点击「立即更新」才执行代码拉取，成功后手动刷新。成功检查缓存一小时，失败静默等待十五分钟，手动「检查版本」可立即重试。安装新版并刷新后，提醒会按已安装版本重新判断。ZIP 安装、权限或 Git 问题可使用面板里的下载和扩展管理入口。

完整新手步骤见 [新手入门](quickstart.md)，各功能教程见 [仓库首页](../README.md)。侧边栏「更新日志」可离线查看版本记录。

## 回退

从 Releases 选择此前版本，下载前端包覆盖对应扩展目录；后端也使用对应版本的 ZIP。保留扩展目录中的 `.git`（若有），避免丢失仓库更新入口。

回退后重启、刷新，再恢复该版本升级前的配置备份。新版导出的备份不保证能由旧版读取；插件会拒绝比自身更新的备份。

安装脚本的代码备份保存在酒馆的 `backups/linghuashi/`。它不含完整账号数据，也不能替代作品备份。
