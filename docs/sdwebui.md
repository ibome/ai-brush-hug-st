# SDWebUI 原生接入

[返回教程目录](../README.md)

在「插件设置 → 模式」选择 **SDWebUI**，再打开「接口配置」。

## 服务连接

1. 为 Automatic1111 SDWebUI 启用 `--api`。兼容分支需要提供相同的原生 API。
2. 填服务地址，例如 `https://example.com`、`https://example.com/sdapi/v1/` 或带反向代理前缀的 `https://example.com/sdwebui`。不要填酒馆自身地址，除非管理员配置了转发。
3. 根据服务选择无鉴权、Basic 账号密码或 Bearer 访问令牌。Basic 对应原生 `--api-auth`；Bearer 适用于使用令牌的代理。
4. 点击「获取模型与参数列表」。连接测试只读取列表，不生图、不扣生图费用，也不修改服务模型。
5. 选择模型，填写提示词，保存或另存为预设。模型留空跟随服务当前模型；列表未提供的名称也可手动填写。

密码和令牌使用插件秘钥库保存，设置和预设只保留引用。更换账号时应保存对应命名接口。刷新后可恢复已保存连接；换浏览器或设备时，通过包含秘钥的加密备份迁移。

酒馆页面需要能直接访问 SDWebUI。HTTPS 酒馆应使用 HTTPS 远程接口，服务需允许酒馆站点跨域访问。`127.0.0.1` 指浏览器所在电脑。仅网页可访问但没有启用 API 的服务不能使用本模式。

## 参数和操作

- 文生图：画师串、正向和负面提示词、尺寸、步数、CFG、采样器、调度器、种子、批量、VAE、CLIP Skip、面部修复和无缝平铺。
- LoRA：获取列表后选择名称、设置权重，加入正向提示词；也可手动填写 `<lora:名称:权重>`。
- 高清修复：仅用于文生图，可选算法、倍数、第二次步数与重绘强度。第一次和修复后的尺寸不同。
- 图生图：在「高级生图」选择图生图，上传底图，调整重绘强度。
- 局部重绘：上传底图并编辑蒙版，白色区域重绘。可配置蒙版模糊、区域填充、局部处理和边距。
- 图片放大：在「高级生图」选择图片放大，上传底图，设置算法及倍数。它使用 extras 原生接口，无需填写提示词。

宽高为 8 的倍数，基础及高清修复单边最多 4096 像素；extras 放大单边最多 8192 像素，每次最多 8 张。素材还受既有图片大小限制。实际模型和硬件可能支持更低上限；高尺寸、批量与高清修复会增加显存和耗时。

模型、VAE 和 CLIP 设置随单次请求临时覆盖，并要求服务结束后恢复原设置。插件不调用全局设置写入或全局中断接口。

## 任务与图片

任务沿用现有排队、并发、持久化和结果保存。已返回的图片可继续保存，不重复提交生图；刷新后尚未提交的任务等待手动继续。请求已发出但未收到响应时，状态可能为「结果待核对」，需要先在 SDWebUI 检查，避免重复生成。

服务同时支持客户端指定任务编号与对应进度查询时，显示当前任务实际百分比。旧版本或不提供相关能力的兼容服务只显示阶段与耗时。不会用其他用户正在执行任务的百分比冒充本任务。

点击取消会停止插件本地等待，SDWebUI 可能继续执行已接收的请求。原生全局中断无法保证只影响当前调用，因此插件不发送该操作。

图片进入绘图管理，可筛选 SDWebUI 来源、载入参数、单图编辑和保存历史版本。返回的种子及模型信息优先于请求值；尺寸以实际图片为准。高清修复记录同时保留基础尺寸与修复倍率，载入后可重复原来的操作。

聊天配图、角色档案、画师串库、中文标签、可视化提示词、组合生图与扩展 API 同样支持本模式。可视化标签使用 SD 权重语法。

## 兼容范围

以 Automatic1111 原生 API 为基准；不同 Forge 分支、自定义脚本和 ControlNet 扩展的额外字段尚未单独适配。可选列表接口缺失时仍可手动配置。OpenAPI 没有公开对应能力时，不启用任务百分比。

本版本完成原生协议模拟测试，尚未连接真实 GPU 服务验收。

参考：Automatic1111 官方仓库的 `modules/api/api.py`、`modules/api/models.py`、`modules/progress.py` 与 API Wiki。
