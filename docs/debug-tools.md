# 调试工具

从灵画师侧边栏打开「调试工具」。接口连接失败或生图失败时，也可以点击「打开调试工具」。

## 网络检测

选择 NovelAI、OpenAI 兼容、ComfyUI、SDWebUI 或「提示词助手 · 独立 API」，再点「检测当前设备网络」。读取所选接口已保存的连接配置，不改变当前生图模式。检测不提交文字或图片生成；鉴权检查会向当前接口发送对应凭据。

独立文字接口连不上时，选择「提示词助手 · 独立 API」，也可在提示词助手配置旁点击「检测助手网络」。日志应显示 `provider: assistant`，不能用 `provider: novelai` 的图片接口日志判断助手是否可连接。该检测只读取助手地址下的模型列表，成功仍不代表所选模型支持聊天补全。独立 API 由当前浏览器直接访问，跟随酒馆由酒馆服务器访问，两者可能有不同的网络出口与跨域条件。

查看 HTTP 状态、耗时和检测结论。浏览器的网络错误不能精确区分 DNS、代理、TLS 和跨域，能打开其他外网也不能证明当前接口已走代理。不透明响应不能验证鉴权或实际生图权限。

TauriTavern 日志会标记 `host: tauritavern` 与 `requestTransport: webview-direct`。插件生图和独立 API 不自动使用宿主 Request Proxy；「酒馆服务器」存图位于本机数据目录。具体边界见 [TauriTavern](tauritavern.md)。

## 存储与缓存

点击「检测存储与缓存」，保持页面在前台，等待结果。

- 设置缓存：用独立的约 1 KB 临时键写入、读回并清理。
- 图片数据库：用独立临时数据库写入约 1 KB Blob，读回校验后关闭并删除测试数据库。
- 站点容量：读取浏览器提供的使用量、配额和持久化状态，不申请权限。
- 当前账号数据库：只统计图库、任务缓存和参考素材数量，不加载图片或聊天内容。
- 酒馆账号目录：只读取原图和缩略图数量，不上传测试文件，不删除用户文件。
- 页面响应：短时间采样前台页面调度延迟，后台页面跳过。

浏览器容量估计属于同一站点，不是灵画师独占配额，也不是服务器磁盘剩余容量。1 KB 试写成功不能保证大图或整批图片成功。没有容量 API 不表示空间已满。

工具不会清空缓存、图片、秘钥、任务或聊天。需要整理时，先通过「备份与恢复」导出资料，再在绘图管理中选择需要删除的作品。

## 失败与卡顿反馈

先复现一次问题，再打开调试工具检查「最近失败记录」。日志会注明提交生图、保存响应、处理缩略图、保存图片、刷新图库或同步任务等阶段，以及 HTTP 状态和是否保留响应。

若已保留接口响应，可在原页面尝试「继续取图 / 保存」，避免主动重新生成。浏览器若连任务响应也无法保存，关闭页面后不一定能恢复，不要把刷新当成重试保存的方法。

卡顿时可先以顺序队列、并发 1、每次 1 张和较小尺寸对比。工具的短期采样不能覆盖整次生图，也不能代替设备内存与服务器日志分析。

完成检测后点击「复制调试日志」或「下载日志」，手动发给作者。浏览器限制自动复制时，日志会展开并选中，可长按复制。日志不自动发送，不包含秘钥、认证头、提示词、聊天正文、账号或图片文件名；最近失败只保留当前页面内最近 20 条。

## 普通 HTTP 酒馆

普通 HTTP 地址可能没有原生 `crypto.randomUUID` 和 `crypto.subtle`。0.24.0 提供安全随机 UUID 与 SHA-256 兼容处理，普通生图、图片保存、参考素材和聊天关联仍可使用。

加密备份需要浏览器安全环境，仍要求 HTTPS 或本机 localhost；不满足时会明确提示，普通备份不受此限制。
