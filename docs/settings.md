# 插件设置

[返回教程目录](../README.md)

入口：左侧导航「插件设置」。当前输入通常自动保存；命名预设、角色档案和画师串各自仍有保存按钮。

## 插件、模式与外观

| 控件 | 用法 |
| --- | --- |
| 插件开关 | 关闭后停止接收新的生图操作，聊天正文恢复显示；已有记录保留，不改变悬浮球的显示选择。 |
| 显示悬浮球 | 独立控制酒馆页面上的透明人物图标，插件关闭时也可保留入口。点击图标展开菜单，可打开设置或关闭悬浮球。 |
| 允许其他扩展调用生图 | 允许通过扩展 API 提交新任务。关闭后已有任务仍可查询和取消。 |
| 模式 | 选择 NovelAI、OpenAI 兼容、ComfyUI 或 SDWebUI。各模式保留自己的连接和参数。 |
| 主题 | 切换人物图标、配色、装饰、悬浮菜单和等待小人。 |

主题包括鲸鱼娘、Claude 小姐、薄荷绿 Gemini 娘、GPT 娘、GLM 娘、Kimi 公主、Grok 小姐、美国豆包和古装男神。窗口顶部可切换明暗外观和窗口大小。

关闭悬浮球后，从酒馆扩展设置重新进入灵画师，即可再次开启。更换主题只影响外观，不更换接口或模型。

## 排队与并发

- **排队生图**：默认模式。一个任务完成后，等待设定的间隔再开始下一个，默认间隔 3 秒。
- **并发生图**：同时执行多个任务，默认并发 2 个，可设置 1 至 16 个。

并发数量指任务数，不等于单次请求的图片张数。服务自己的并发上限、限流和工作流批量输出仍然生效。刚配置好服务时建议先保持排队。

## 触发与展示

| 设置 | 含义 | 新安装默认值 |
| --- | --- | --- |
| 自动生图 | 新角色回复完成后识别包裹格式中的提示词并进入生图流程；关闭后可以手动点按钮。 | 开启 |
| 生成前确认提示词 | 先打开本次任务的检查／修改窗口，确认后才提交。 | 关闭 |
| 在聊天中显示图片 | 在原提示词位置显示图片；关闭后显示原文，图库中的图片保留。 | 开启 |

默认前缀是 `image###`，后缀是 `###`。界面提供前后缀输入框；修改时，也要同步修改文字模型使用的输出约定。示例：

```text
image###1girl, reading a book, warm light###
```

自动生图只处理新回复，不会因打开旧聊天或刷新页面而批量补画历史消息。提示词助手的「自动准备配图提示词」与「准备后自动生图」另行控制，详见 [聊天与助手](chat-assistant.md)。

## 图片存储与清理

| 位置 | 特点 |
| --- | --- |
| 浏览器 | 当前浏览器、当前账号的图片库；清除站点数据或换浏览器后不会自动恢复。 |
| 酒馆服务器 | 使用酒馆自带接口保存到当前账号目录，无需额外组件，同账号换设备可读取作品与参数。 |

切换位置后显示的是对应图库，不会自动搬迁原有图片。选择酒馆服务器时，可用「迁移浏览器图片」搬迁，迁移前建议备份。图片数量与占用空间针对当前存储位置。

内置账号存储在打开酒馆页面时执行清理；关闭页面后的清理和跨设备任务恢复由可选服务器增强组件提供。侧边栏「扩展组件」可检查状态并下载。

自动清理可选不清理、按时间清理、达到数量后清理指定天数以前的图片。收藏和聊天关联的保护规则见 [绘图管理、存储与任务](gallery-tasks.md)。「一键清空」有确认步骤，清空前先核对当前存储位置并导出需要的作品。

## 备份、版本与更新日志

- 「备份与迁移」：导出配置、完整作品和分享包，或预览并恢复备份。
- 侧边栏「更新日志」顶部的「版本与更新」：查询 GitHub 发布版本、服务器组件版本及协议。插件设置保留「备份与迁移」。
- GitHub 正式发布新版后，扩展列表显示「有更新 v版本号」，当前主题的透明 Q 版人物喊「插件更新啦！」。点击进入更新页；同一版本关闭后不再重复出现。
- 打开灵画师也会复用后台检查结果；有新版时，侧边栏「更新日志」右侧显示红色感叹号，点击后自动展开更新动态、主题人物和更新按钮。查看后保留标记，更新下载完成后清除。
- 更新页点击「立即更新」，通过酒馆原生接口更新 Git 安装；完成后手动刷新酒馆。ZIP 安装下载前端 ZIP 覆盖，全局安装需管理账号。
- 进入酒馆后在后台检查，成功结果缓存一小时，失败等待十五分钟再试；断网或查询受限不会弹窗。手动「检查版本」可立即查询，多个检查共用一次请求。
- 侧边栏「更新日志」：查看随当前安装包提供的全部版本记录，支持逐项折叠和全部展开／收起，无需联网。

任务、助手、编辑或备份尚未完成时，请先等待结束再更新。安装和回退见 [安装与更新](install.md)，备份见 [备份与恢复](backup.md)。

## 重置设置

设置填乱时，在「插件设置 → 重置设置」选择需要恢复的范围。默认勾选常规设置和当前生图参数，助手规则需单独勾选；确认后才执行。

所有接口地址、秘钥、认证方式、模型及连接兼容参数保留，不要求先重新鉴权；主题、存储位置、图库、任务和素材库也保留。NovelAI 当前参数重置后恢复内置画师串和负面词。操作前可先备份参数，完整范围见 [重置说明](backup.md)。
