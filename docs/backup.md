# 备份与恢复

[返回教程目录](../README.md)

## 按步骤备份与换设备

1. 打开「插件设置 → 备份与迁移」。
2. 只搬设置选配置备份；连作品一起搬选完整备份；给别人分享可选分享包。
3. 勾选需要的分区。完整备份还要选浏览器或酒馆服务器图库。
4. 个人备份要带走 Key 时勾选「包含秘钥并加密整个备份」，填写至少 8 个字符的密码，导出 `.lhbackup`；不含秘钥时导出 ZIP。
5. 在目标设备选择文件，需要时输入密码，先核对导入预览。
6. 选择合并或覆盖、要恢复的分区与图片位置，确认后等待完成。
7. 核对接口、预设、参考素材及图库，再实际测试一张图。

分享包可逐条选择预设、画师串和角色档案，不包含秘钥。个人备份密码不会保存，丢失后无法由插件找回。

## 包含哪些内容

配置备份包含勾选的配置分区及其引用素材。完整备份另外包含所选浏览器或服务器存储位置的图片、历史版本、收藏、聊天配图关系和最多 500 条任务记录。分享包可逐项选择已保存预设、画师串和角色档案，也可明确选择包含当前参数。

备份只针对当前账号。要搬迁两个存储位置的作品，分别选择浏览器与酒馆服务器导出。未被任何配置或作品引用的旧素材暂不纳入备份。

## 秘钥

不包含秘钥的配置包保存匿名引用标识。恢复时，同类、同地址连接可保留目标设备已有秘钥，不能借用不同地址的秘钥。

需要带走秘钥时勾选加密选项。整个 ZIP 使用随机盐、随机 IV、600000 次 PBKDF2-SHA256 和 AES-256-GCM 加密。密码不上传给生图服务，也不保存到设置；请自行保管密码。

备份会在导出前读取已有秘钥。读取失败会阻止含秘钥备份，避免误认为已完整保存。可修复秘钥后重试，或取消包含秘钥。

## 恢复

导入预览前检查路径、数量、大小、文件 SHA256 和素材完整性；加密备份还检查认证标签。校验失败不会应用配置。

合并添加库项目，保留当前开关、参数、接口选择和已有同内容条目。ID 冲突和同名但内容不同的条目另存，并重新关联预设绑定。

覆盖只替换勾选分区。图片始终追加或复用已有文件，不按备份删除当前图库。恢复中途失败，已写入素材和图片保留，可重新导入；已有同 ID 同内容图片不会重复保存。

确认恢复前，插件保存一份本设备当前账号配置，供「撤回上次配置恢复」使用。撤回不删除导入的图片和素材。

## 聊天和任务

来自当前账号、当前酒馆的备份默认勾选聊天关联；其他来源默认关闭。重新启用关联，需要原角色卡、聊天标识和消息分支仍对应。插件不备份酒馆聊天正文或角色卡文件。

已有聊天关联优先保留，恢复不会覆盖较新的配图状态。没有图片的旧记录恢复为失败记录，不会自动排队。

任务以归档恢复，不加入执行队列、不重发收费请求。归档中可载入参数，到生图工坊手动生成。远程执行状态、未保存响应和 ComfyUI 运行中的任务不能通过此包迁移。

## 容量

单个备份包最多 200 MB、最多 500 张作品；超出时分批使用绘图管理的 ZIP 导出。参考素材单份最多 4 MB，参考库维持既有账号容量限制。
