# 生图工坊与高级生图

[返回教程目录](../README.md)

入口：「生图工坊」。接口地址和 Key 在 [接口配置](interfaces.md) 管理；工坊使用当前选定模式的连接和参数。

## 一次普通文生图

1. 载入需要的参数预设，核对模型和接口。
2. 填画师／风格、正向提示词和服务支持的负面提示词。
3. 选择尺寸、步数、种子和张数；需要时展开其他参数。
4. 核对「出场人物」，避免无意带入此前的角色。
5. 点击「生成图像」，在任务区域查看排队、绘制、取图和保存状态。

图片成功保存后进入绘图管理。只有服务明确提供当前任务进度时才显示百分比，其他时候显示实际阶段。不同主题使用对应奔跑小人，重画期间保留原图。

想复现某张图时，从其大图详情导入参数并保留种子；想探索不同结果时使用随机种子。相同种子也不保证跨模型、跨服务或不同版本得到完全相同的图片。

## 参考图、图生图与局部重绘

| 操作 | 必要输入 | 用途 |
| --- | --- | --- |
| 参考生图 | 参考图及提示词 | 参考画风、人物或图像信息重新构图 |
| 图生图 | 底图、提示词、重绘强度 | 以现有图片为起点改变内容 |
| 局部重绘 | 底图、蒙版、提示词 | 指定区域修改，尽量保留其他部分 |

### 图生图

1. 在「高级生图」选择图生图，上传底图，或从图库选取。
2. 需要保持比例时点击「使用底图尺寸」。
3. 填目标描述，调整重绘强度；强度越高通常变化越大。
4. 生成并比较结果，不满意时调整一个参数再试。

图生图不要求手动画蒙版。其界面与局部重绘共用底图设置，但局部重绘额外需要编辑蒙版。

### 局部重绘

1. 选择局部重绘，上传或选择底图。
2. 打开蒙版编辑，用笔刷涂出要改变的区域，橡皮擦可修正；支持撤销、重做。
3. 保存蒙版，填写局部目标描述并调整强度。
4. 核对保留蒙版外像素等选项，再生成。

蒙版表示重绘区域。插件会转换为各服务需要的格式；不要把 OpenAI 透明区域蒙版与 ComfyUI 节点蒙版当成同一种上传格式自行混用。尚未保存的绘制会在提交前处理。

从单图编辑进入这些操作，会把结果保存为原图组的新版本。直接从工坊生成则按当前任务保存。

## NovelAI 参考能力

### Vibe 画风参考

第一次使用请看 [氛围转移新手教程 · Vibe](novelai-vibe.md)，包含操作示意、上传图片与导入编码两条路线、编码按钮位置、参数解释和常见错误。

1. 选择参考生图和「画风参考 · Vibe」。
2. 添加参考图，分别设置启用、参考强度和信息提取量。
3. V4／V4.5 按界面要求编码后生成；编码可能消耗服务额度。
4. 多图时可归一化总强度，避免叠加过强。
5. 常用参考可保存到 Vibe 素材库，填写名称、分类和默认强度，之后搜索载入。

最多 8 份 Vibe。编码按模型和信息提取量缓存；改变模型或提取量可能需要重新编码。支持 `.naiv4vibe` 导入导出，图库参考图和素材库不等于已对所有模型完成编码。

### V4.5 人物参考

1. 选择支持的 V4.5 模型。
2. 在参考用途中切到人物参考，上传人物图。
3. 选择人物或人物与画风，调整保真度和强度。
4. 添加画面提示词后生成。

角色档案中的参考图可以载入此处，但档案里保存了图像并不代表所有接口都支持原生人物参考。Vibe 与人物参考按当前用途使用。

### 图片增强

在绘图管理的大图详情或单图编辑点「图片增强」，选择高清放大、细节增强或导演工具。结果追加到历史版本。具体步骤和尺寸限制见 [NovelAI 图片增强](novelai-processing.md)。

## ComfyUI 与 SDWebUI

ComfyUI 的高级选项依赖工作流节点与映射。可用模板作为起点；复杂 LoRA 分支、自定义节点和输出选择先在服务中验证。参考 [接口配置](interfaces.md)。

SDWebUI 的高清修复用于文生图；extras 图片放大只需底图与算法，不要求提示词。局部重绘还可以配置区域填充、模糊、局部处理和边距。参考 [SDWebUI 教程](sdwebui.md)。

## OpenAI 图片编辑

先在接口配置中明确开启图片编辑能力，再添加参考图、底图或蒙版。最多使用 4 张参考图；具体服务可能限制更少。支持的模型、透明蒙版和额外参数以服务实现为准，不会因文生图可用而自动开启图片编辑。

## 组合生图

入口在生图工坊参数预设操作区，**「另存为」右侧的「组合生图」**。侧边栏没有独立组合生图项。

1. 先配置好一个可以单独生成的预设。
2. 打开组合生图，主体、动作／场景、风格三栏分别每行填写一个候选，也可加入素材卡。
3. 选择每组重复次数和种子方式。
4. 点击「预览组合」，检查展开后的提示词、任务数和预计图片数。
5. 确认后点击「提交全部组合」。

例如 2 个主体、2 个动作、2 个风格得到 8 个组合；每组重复 2 次就是 16 个任务。每次最多 32 个任务，使用当前排队／并发设置。普通 OpenAI 模型由服务决定种子，ComfyUI 张数还取决于工作流输出。

「同种子对比」适合比较风格，「逐张递增」便于追踪，「逐张随机」适合探索。暂停等待任务不会停止已提交的任务；刷新后未提交的组合等待手动继续。

## 画风探索

1. 切到组合生图的画风探索模式。
2. 从画师串库选择最多 12 个画师，设每组 1 至 3 人。
3. 预览候选，核对画师、关联质量词和负面词。
4. 可以先把喜欢的组合命名保存到画师串库，再提交绘图。

预览组合和编辑素材不调用图片模型；提交绘图才产生实际请求。

## 素材与参数保存

底图、参考图和蒙版独立保存为素材，预设及任务保存其引用。单份素材最多 4 MB；浏览器最多 128 份，服务器素材总量最多 128 MB。常规上传会按现有规则规范化尺寸与格式，模型本身还有额外限制。

移除页面中的引用不会立即删除素材文件，以免破坏旧预设和任务。跨设备迁移时，使用包含引用素材的配置备份，不能只复制提示词或参数 JSON。
