# 0.26.0 功能说明与图文教程

[返回仓库首页](../../README.md) · [当前安装版新手教程](../quickstart.md) · [更新记录](../../CHANGELOG.md)

**适用版本：2026-10-24 正式发布的 0.26.0，构建 `20261024-comic-assistant-release`。** 包含此前测试版的漫画、助手、恢复与手机优化；[完整发行说明](../releases/v0.26.0.md) 列出功能、修复和升级步骤。

安装旧版或此前的本地测试版时，先备份，再在酒馆扩展列表更新并刷新。若版本仍为 0.25.0，核对扩展是否更新到官方仓库，以及是否有重复安装。找不到新入口时不要重置 Key 或删除图库。

## 按目标阅读

| 目标 | 操作教程 | 会用到的接口 |
| --- | --- | --- |
| 配好服务并画出第一张图 | [从安装到第一张图](first-run.md) | 图片接口 |
| 中文描述转提示词、聊天自动配图 | [提示词助手与聊天配图](assistant.md) | 文字接口；确认绘图后使用图片接口 |
| 剧情转分镜、配图、排对白、做章节 | [漫画工坊完整流程](comic.md) | AI 分镜用文字接口，逐格绘图用图片接口 |
| 找回工作稿、保存作品、图文导出、换设备 | [草稿、图片与备份](recovery-export.md) | 本地数据与酒馆存储；不会因导出调用模型 |

第一次使用推荐顺序：**先手动成功一张图 → 再配置文字助手 → 最后尝试两格漫画**。暂时不需要的功能可以保持关闭。

## 近期补充了什么

| 功能 | 可以做什么 | 使用边界 |
| --- | --- | --- |
| 首次使用引导 | 按手动绘图、聊天配图、漫画选择检查清单 | 配置完整、连接通过、实际调用成功分别显示 |
| 常用/完整设置 | 先展示常用参数，需要时展开高级选项 | 收起的配置仍生效，不会被清空 |
| 任务提示词 | 按七类任务修改前置要求和底层规则 | 必须保留结果字段与必要动态标记 |
| 酒馆预设与请求预览 | 读取已开启的可发送文字条目，核对顺序与实际上下文 | 角色卡、世界书和聊天上下文仍按对应任务配置读取 |
| 独立 API 酒馆转发 | 通过酒馆连接独立文字接口 | 使用酒馆所在设备的网络，不自动借用手机代理 |
| 模型兼容与预算 | 保存模型的输出参数、限制和返回方式，估算请求 | 131072 是插件输入上限，不保证模型支持 |
| 多画面与差异采用 | 单次规划多个画面，单独调整其中一幅 | 采用草稿与提交图片是两个步骤 |
| 草稿与回复恢复 | 找到未保存规则、历史画面和失败回复 | 不等于备份图片，恢复不自动执行任务 |
| 漫画工坊 | 分镜、单格修改、逐格绘图、选用旧图 | 每章最多 12 格，每项目最多 6 个角色 |
| 漫画排版 | 模板、对白、气泡拖动、尾巴、主体保护区和位置建议 | 主体保护区手动设置，不是自动识别人脸 |
| 系列与章节 | 命名、排序、归档、按需加载和系列带图备份 | 最多 200 章，同时加载最多 8 章 |
| 图文阅读 | 按楼层阅读当前聊天配图并导出 | 只使用当前回复分支与选中的图片版本 |
| 图库与版本 | 参数分批核对、快速筛图、单图编辑与历史切换 | 浏览器原图仍只在原设备，切换存储不会迁移 |
| 本地反推与超分 | WD 标签反推、FSRCNN 2×/4× 放大 | 可选组件，需要组件主机和独立模型 |
| 手机与错误恢复 | 保留导航和滚动、紧凑对白编辑、按失败阶段给入口 | 浏览器下载、系统分享和内存限制因设备而异 |

此前的四种图片接口、中文标签库、画师串库、角色档案、NovelAI 增强和扩展 API 继续保留，基础用法见 [首页教程目录](../../README.md#使用教程)。

## 验证范围

近期更新已通过 648 项自动化用例，并在酒馆内置浏览器检查了模型列表、标签搜索、320px 手机排版、图片编辑与历史版本、漫画气泡拖动和存储诊断。

以下内容仍需实际使用时核对：

- 没有在本次教程制作中重新提交付费文字或生图请求。
- WebKit 回归不等同于真实 iPhone Firefox、Safari 或 TauriTavern 真机验收。
- 存储检测的小数据试写成功，不保证整批大图都能保存。
- 已生成导出文件和下载入口，不代表浏览器已将文件保存到设备。
- 控制台迟到加载分支已有修复，但未强制复现超过 20 秒的真实慢网场景。

当前排版为四种规则模板，尚未提供自由斜切分格、跨格叠放小格、竖排气泡或独立拟声字图层。参考漫画的画风主要由图片模型决定，人物一致性也受模型能力影响。
