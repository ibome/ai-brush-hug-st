# 漫画工坊

入口位于侧边栏「提示词助手」下方。漫画项目独立保存，切换聊天不会改写已经复制的剧情。

## 1. 剧情与分镜

1. 新建漫画项目，输入名称和计划格数（1—12 格）。
2. 直接输入剧情，或读取最新角色回复、指定起止楼层。楼层按聊天消息顺序计数，包含用户消息；系统消息会跳过。正在输出的聊天需等待完成。
3. 在工坊「添加项目角色」选择档案并添加，可直接选择服装和移除角色；也可「同步当前角色档案」。每个项目最多 6 个角色，保存独立角色快照，修改不影响档案库；之后修改原档案也不会自动改变已有漫画。
4. 设置统一画风和负面提示词，展开「分镜调用设置」核对模型、预设、返回方式和最大输出 Token。文字接口沿用「提示词助手」的来源、地址、秘钥与直连/酒馆转发路线；模型可为此项目单独填写。新项目默认仅使用分镜内置规则，最大输出 4000 Token；旧项目继续沿用原有助手设置。
5. 需要聊天预设时选择「酒馆当前预设」，全部启用文字条目按原生顺序发送；也可选择沿用助手的预设选择。这些设置只影响当前漫画，不修改酒馆聊天与提示词助手配置。点击「AI 创建分镜」会调用文字模型。
6. 审阅分镜后点击「采用分镜」。可以手动添加空白格、调整顺序、编辑镜头、画面描述、生图提示词和出场人物的动作表情。重新采用分镜会替换当前分镜，旧图仍保留在绘图管理中。自定义项目名保留。
7. 选中画格后，在「单格 AI 修改」填写要求，例如「保留人物，改成夜晚近景」，可选择保留出场人物及旁白对白。点击「AI 修改本格」只调用文字模型，先显示当前/修改后的字段差异，手动采用才写回此格；原图、图片版本和其他画格保留，可撤销。需要重新配图时再手动确认生图。结果按本设备账号恢复；修改剧情、角色、画格或文字接口后，旧结果需要重新生成。

模型回复被截断时，可减少格数、缩短剧情或提高本项目的最大输出 Token 后手动重试。格式失败时直接展开「查看失败回复」，可以编辑文字并点击「重新解析此回复」；此操作在本地执行。插件能提取说明文字或代码块中的一份完整分镜 JSON，遇到多份结果、缺失字段或格数不符仍会明确提示。复制脱敏诊断只包含调用路线、模型、阶段耗时等信息，不包含回复原文。失败不会自动调用模型或生图。

待确认分镜和失败回复会自动保存到当前设备、当前账号的浏览器恢复记录；刷新后恢复，仍需手动采用，不会自动调用模型。修改标题保留结果；修改剧情、角色、格数或已有画格内容后会标记旧结果失效，避免覆盖后来的手动编辑。切换项目、页面或刷新时记住当前流程页、所选画格和滚动位置。恢复记录不随项目 JSON 导出，也不跨设备同步；清除站点数据会删除本设备恢复记录。浏览器拒绝存储或容量不足时页面会显示保存警告，原有已保存记录保留。已有空白项目会被复用，减少重复的「未命名漫画」。

项目操作下方增加撤销、重做及「编辑历史」。连续输入合并为一次编辑；采用分镜、同步角色、删除画格、调整顺序、修改对白、移动气泡及选图前均保留快照。每个项目最多 12 次，所有恢复记录合计上限约 1.5 MB，达到上限时优先清理较早的历史，保留当前草稿。恢复前的项目也会保留，方便撤回恢复操作。撤销普通文字编辑不会移除后来生成的图片，图片版本和任务关联保留；项目存在未完成或待核对任务时暂停恢复入口。删除整个项目会同时清除其本设备编辑历史，图片仍保留。

读取聊天会移除思考块、图片标签和 HTML 标签，载入后可在「剧情正文」核对内容再分析。项目角色可单独选择服装、锁定外观和服装；它们是项目快照，文字约束仍不能保证跨格完全一致。

每个项目角色可上传或替换参考图，再在「生图人物参考」选择一个角色。参考图只在该角色出场时使用；NovelAI V4.5 支持人物参考，OpenAI 兼容接口需先启用图片编辑支持。其他接口或模型会在提交前明确提示；不自动忽略已选参考，也不自动切换接口。参考图是项目专用素材，清除绑定不会删除档案库内容。跨设备需通过完整备份迁移参考素材。

## 2. 画格生成

- 复用当前「接口配置」和生图工坊的模型、尺寸等参数，每格提交 1 张，使用随机种子和文生图模式。ComfyUI 需要选择能执行文生图的工作流。
- 「生成未配图画格」选择尚未配图或已确认原图缺失的格子；单格「再画一张」保留现有图片。临时无法连接存储的格子不会被自动选为缺图。
- 提交前显示接口配置名、模型、尺寸、步数、图片保存位置与格数，可展开每格实际正负提示词。确认绑定本次画格与接口配置，变化后须重新确认；通过校验后使用本次预先检查的请求提交，配置在保存任务期间变化时保留暂停任务，不直接提交。点击「确认生成」才会发出生图请求。费用取决于所选服务，不将估算当作实际扣费。
- 「仅重试失败格」选择最近任务明确失败的画格，已有成功图片保留。提交结果不确定的任务仍需先到任务记录中核对。
- 每格显示任务状态；暂停、失败和提交结果不确定的任务在「生图工坊 → 任务记录」中手动处理。刷新不会自动重新提交。
- 已生成作品保存到当前图片存储位置，并自动收藏以避免常规清理。删除项目不会自动删除图片；手动删除图片或清除浏览器数据仍可能导致缺图。
- 下拉「图片版本」可以选择本格之前生成的图片，最多记录最近 16 张。
- 每格右上角的图片按钮可打开「选用图库图片」，在当前浏览器或酒馆服务器图片间选择，支持按名称、提示词搜索、仅收藏筛选及每页 24 张的分页。选用时核对图片仍然存在，并自动收藏；不复制原图、不调用模型、不修改全局存储位置。本格原图保留在图片版本中。跨设备读取浏览器图片仍需要迁移图片备份。
- 每格右上角的铅笔直接跳转到该格的提示词编辑区，保留当前图片。修改提示词后，回到画格生成并手动确认重画才会提交任务。
- 顶部任务汇总分别统计已配图、排队中、生成中、失败、待继续和待核对画格。已有原图的重画任务仍显示实际状态；暂停或提交结果不确定时，可直接进入任务记录核对。配图进度条表示已有图片的格数，不代表接口内部的生图百分比。
- 「检测图片」会检查当前引用及原图可读性，区分正在检测、原图可用、图片缺失和存储暂时无法读取。服务器优先发送只读 HEAD 请求，不支持时回退只读 GET 并取消正文读取；普通刷新短期复用检测结果。找不到图片时显示具体画格，可选择其他版本、选用图库图片、恢复备份或手动补画；鉴权、网络和服务器错误不会清空原引用或当作图片已删除。浏览器图片只检查当前设备。

## 3. 排版与对白

可选择条漫、四格分页或双列，调整阅读方向、画格比例、完整显示/居中裁切、画格间距和对白字号。新项目默认自动匹配图片比例并完整显示；已保存的项目保留原选择。

每格可输入旁白，最多添加 4 个对白气泡。每个气泡独立设置说话人、正文、对话/内心独白、横纵位置和宽度，可选择是否显示说话人及自动适配宽度。中文换行避免把句号等标点单独放在行首。桌面宽屏并排显示编辑区和预览；手机通过「编辑 / 预览」切换，预览只显示所选画格所在页，可在预览顶部切换画格，切换后保留当前模式。

可在预览上拖动气泡，使用气泡右下角的宽度手柄调整大小，手机手柄为 44px；也可用滑块调整。手动调整宽度会关闭该气泡的自动适配。对白过长时请缩短文字、加宽气泡或拆到其他画格；位置接近边缘时会约束在画格内。气泡尾巴可选无、上、下、左、右，并单独调整起点和长度；内心独白用小圆点表示尾巴。

「排版模板」包含竖屏条漫、经典四格、横向双列和竖幅双列，保留当前阅读方向；采用模板可撤销，不改写对白。「本格主体保护区（手动）」用于框出应避开的主体位置，虚线区域只在预览显示，不会画进导出图片。它不是人脸识别，也不自动定位人物。

点击「在图片上编辑保护区」或预览上方的「编辑主体保护区」，可直接在画格图片上拖动框选区域、拖动已有区域移动位置、使用右下角手柄调整宽高。精确调整时填写左侧、顶部、宽度和高度的百分比；关闭「避开此区域」可暂时停用。每次拖动只保存一次编辑，可撤销；拖动被系统取消时保留原位置。编辑保护区时暂停气泡拖动，点击「完成保护区编辑」恢复。修改保护区后需重新预览位置建议。

点击「预览本格位置建议」在本地计算气泡位置，尽量避开保护区与其他气泡。先显示预览，点击「采用建议」才保存，可撤销；取消建议保留原位置。区域太拥挤时会提示剩余遮挡，不删除或改写对白。预览期间修改排版会使建议失效。导出检查会同时提示气泡重叠和手动保护区遮挡。

对白由插件绘制，生图提示词会要求模型不要画文字和气泡。修改对白或排版不会调用文字模型或图片接口。

## 4. 阅读与导出

先选择导出清晰度（轻量 720px、标准 960px、高清 1440px）和页码；留空导出全部，也可填写 `1-3` 或 `1,3`。页码以当前版式为准，条漫通常为一页，四格分页最多每页 4 格。点击「导出前检查」查看所选页的宽高与长图预计尺寸，识别缺图、暂时无法读取的图片、对白溢出、文字过小及气泡重叠。可点击「前往画格」修正。缺图和溢出会阻止导出；排版警告需调整或手动勾选「已核对排版警告，仍然导出」。实际导出会重新检查。

- **长图**：把所选页面拼接成 PNG。
- **分页图片**：导出 PNG ZIP，文件名保留原页码；四格模式每页最多 4 格。
- **离线 HTML**：包含所选页排版图片及对应可展开文字，离线打开即可阅读，不依赖酒馆接口。
- **项目配置**：顶部文件按钮导出 JSON，包含剧情、分镜、对白、角色快照和图片引用。JSON 不包含图片文件；迁移设备时应同时备份绘图管理中的作品。导入不会恢复或重新执行旧任务。
- **项目与配图备份**：导出可继续编辑的 `.comic.zip`，包含项目配置和当前选用的原图。顶部「导入漫画项目」可导入到新的项目，配图保存到当前存储位置，不触发生图。此包不包含图片历史版本或人物参考素材；这些内容请通过完整备份迁移。

文件生成后发起浏览器下载，页面保留「重新下载」「打开文件」和浏览器支持时的「分享文件」。长图同时显示可打开或长按保存的预览；显示已发起下载不代表浏览器已经将文件保存到设备。

预览缓存缩略图及未变化页面，修改提示词不会重复绘制相同页面，手动更新预览会重新检测素材。导出只读取所选页原图，未选页缺图不阻止部分导出；备份包始终包含整个项目，与页码及清晰度无关。缺失图片会标出具体画格；存储连接失败会单独提示，需恢复连接、恢复素材或选择其他版本。章节目录最多 200 章，同时加载最多 8 章，每章最多 12 格；已加载正文与目录合计最多 750 KB。导出原图总量上限 64 MB，画布受移动设备内存限制，超限时请使用四格分页或拆分章节。

个人备份中可选择「漫画项目」。备份漫画配置不等于备份图片，迁移时请一并选择作品。

## 5. 项目整理与章节

顶部「项目整理」打开「系列与章节」，显示缩略图，可按进行中/已归档/全部、系列与名称搜索，列表每页 12 章。填写名称后，「创建并加入本章」一次创建系列并加入当前章节，自动筛选该系列；「仅创建空系列」保留独立创建分组的用法。为本章选择已有系列时，会建议未占用的章节号，编号检查包含已卸载和已归档章节；手动填写重复编号时会阻止保存。可重命名系列或删除分组，删除分组不删除章节。

切换「剧情与分镜」「画格生成」「排版与对白」「阅读与导出」时会收起项目整理，保留搜索、状态、系列筛选和分页位置。再次点击顶部「项目整理」即可继续整理，也可使用区域右上角的收起按钮。

「复制项目」保留剧情、人物、排版与配图引用，生成新的项目和画格标识，移除旧任务关联，副本作为独立项目；不会重新生图，也不会复制原图文件。

填写起止画格后，「复制为新章节」从当前项目复制这一段为独立章节，保留原项目全部内容。「新建续章」沿用人物、画风和版式，清空剧情与画格，供继续编写后续故事。章节号在同系列内递增，包括未加载章节。首次续章会建立同名系列。存在未完成或待核对任务时，先处理任务再复制、拆章或归档。

「保存并卸载本章」先把正文写入当前酒馆账号的 `user/files/linghuashi-comic-内容哈希.json`，校验后设置中只保留目录；原图继续保留在原存储位置。未安装酒馆的设计预览使用本设备 IndexedDB。打开未加载章节时才读取正文。已加载章节达到 8 章后，新建或打开章节会自动卸载最早更新、非当前且没有未完成任务的章节；没有安全候选时明确阻止。写入失败保留已加载原稿，读取失败保留目录，不自动清空或创建空白正文。

归档只改变列表状态；需要减少加载量请卸载正文。目录最多保存 200 章、40 个系列。已写入的账号正文使用不可变内容文件，删除目录项目不会自动清除这些文件，便于配置恢复与回滚；管理员整理前应先完成备份。

筛选某个系列后可「导出配置（不含图片）」，包含该系列所有已加载及未加载章节的可编辑正文，最多 12 MB；顶部导入入口可导入为新的系列和章节，不覆盖原系列、不恢复旧任务。系列 JSON 不包含图片。个人配置/完整备份选择「漫画项目」时会读取并携带所有卸载正文，缺少正文时停止导出，避免生成不完整备份；合并后已加载章节超过 8 章时，先卸载部分当前章节再合并。跨设备迁移还需完整图片与参考素材备份。

「检查系列带图备份」读取整个系列的正文和当前配图，显示章节数、画格数、图片引用复用次数、预计体积及缺图或存储连接问题。尚未配图的空格可保留为可编辑分镜；已引用但无法读取的原图需修复后再打包。检查通过后点击「下载系列与配图」，生成 `.comic-series.zip`；同一图片的引用复用，内容相同的原图在 ZIP 内也只保存一份。系列配置上限 12 MB，当前配图合计上限 64 MB，单张原图上限 20 MB；超过时分章节备份。系列内容变化后需重新检查，读取和打包可以取消。

顶部「导入漫画项目」可识别系列 ZIP，即使文件改名仍按包内格式识别。导入后创建新的系列和章节标识，配图保存到当前图片存储并自动收藏；重复原图复用，不覆盖原系列，不触发文字或生图请求。新章节先保存在章节库，点击打开时加载。导入会检查图片摘要、文件清单、章节编号和容量；保存失败不改写原目录，已经成功保存的原图仍可在图库中找到。系列包仅包含当前配图，不包含旧图片版本、人物参考素材、秘钥或本设备撤销记录；这些内容需要完整备份。
